# Tidoc 使用指南

Tidoc 用于整理报账发票和相关材料。它以一张发票为一个条目，把发票、付款截图、实物图、查验单、实付金额和备注放在一起，再按报账批次导出或打印。

第一次使用时，建议先完成“快速入门”。遇到具体问题时，可按目录直接查找。

## 一、先了解几个概念

### 条目

一张发票对应一个条目，也就是主界面中的一张卡片。发票内容、材料、实付金额、备注、标签和识别结果都保存在这个条目中。

### 材料

材料是报账时需要随发票一起提交的文件和信息：

- 发票 PDF：创建条目和查看原票的主要文件。
- 发票 XML：提供结构化发票数据，与对应 PDF 一起导入。
- 付款截图：记录实际付款情况，可识别截图中的金额。
- 实物图：记录采购物品的照片，可在设置中设为必需。
- 查验单：国家税务总局查验平台生成的 PDF。
- 实付金额：实际支付金额，可以等于发票金额，也可以单独填写。

### 报账人

报账人表示发票归属，包含姓名和审核人。团队中有多人报账时，可以为每个人建立一个报账人。

### 收款信息

收款信息用于生成报账说明和验收单 Word，包含姓名、学号、电话、开户行和卡号。它与报账人是两组独立信息。

### 标签

标签用于分类和筛选，例如“电控”“比赛物资”“待确认用途”。一个条目可以有多个标签。

### 报账批次

报账批次用于组织准备一起提交、导出或打印的条目。批次可以填写备注，提交完成后可以归档。

### `.tidoc` 绑定包

绑定包用于在不同电脑或不同人员之间交接材料。它包含条目、附件、报账人和完整性校验信息。导入前会显示预览，便于确认报账人、审核人、标签和批次。

### 识别提醒和材料齐备

这两个状态分别表示不同内容：

- 识别提醒：发票内容需要核对，例如金额、明细、抬头或购买方税号存在异常。
- 材料齐备：当前材料要求已经满足。

一个条目可能材料已经齐备，同时仍有识别提醒。完成报账整理时需要同时查看这两类状态。

## 二、下载和安装

### 下载地址

- [Tidoc 官网入口](https://www.bitfsae.com/)：首页底部选择「报账软件」。
- [GitHub Releases](https://github.com/totok22/tidoc/releases/latest)：可查看和下载各版本安装包。

### Windows

下载 `tidoc-core-windows-v{version}.exe`，双击后按提示安装。程序默认安装到当前用户目录，安装过程通常无需管理员权限。

安装完成后，开始菜单会出现 Tidoc。安装器也会为 `.tidoc` 绑定包配置文件图标和打开方式。

如果 Edge 或 Windows SmartScreen 显示安全提示：

1. 先确认文件来自 Tidoc 官网或 GitHub Releases。
2. Edge 下载栏中选择「保留」或「仍要保留」。
3. SmartScreen 窗口中选择「更多信息 → 仍要运行」。
4. 由单位统一管理的电脑如果限制安装，请联系设备管理员处理。

### macOS

下载 `tidoc-core-macos-v{version}.dmg`，打开后把 Tidoc 拖入“应用程序”。

macOS 首次打开时如果显示来源提示，可在 Finder 中右键 Tidoc，选择「打开」并再次确认。也可以前往「系统设置 → 隐私与安全性」，在安全提示旁选择允许打开。

## 三、快速入门

下面是一套完整的基础流程。

### 第一步：创建报账人

首次打开 Tidoc 时，按提示创建报账人：

1. 姓名填写发票的实际归属人。
2. 审核人填写负责审核或接收材料的人。
3. 有多位报账人时继续添加。添加第二位后，软件会自动开启代填模式，新建和导入时可以选择归属。

报账人可以随时在「设置 → 报账人 → 管理」中修改。

### 第二步：导入发票

点击右上角「导入发票」，选择一张或多张发票 PDF。也可以直接选择包含多张发票的文件夹。

如果同时有 XML，把 XML 与对应 PDF 放在一起选择。Tidoc 会自动配对，并优先使用 XML 中的结构化数据。

### 第三步：补齐材料

在发票卡片上添加付款截图、实物图和查验单，确认实付金额。材料也可以拖到卡片上，或在条目详情中集中添加。

### 第四步：核对条目

依次查看「待补材料」「识别提醒」「OCR 待确认」视图。打开详情后核对发票字段、明细、材料和备注。处理完成的条目会进入「齐备」。

### 第五步：整理和交付

勾选需要一起提交的条目，建立报账批次。材料准备完成后，根据交付方式选择：

- 导出 `.tidoc` 绑定包，交给其他人继续整理。
- 导出总览 Excel 或附件整理包。
- 使用打印导出组件生成合并 PDF、报账说明和验收单。

## 四、导入发票和材料

### 使用「导入发票」

「导入发票」适合一次处理多张发票：

1. 点击右上角「导入发票」。
2. 选择多个文件，或选择整个文件夹。
3. 在预览中检查识别结果和报账人。
4. 确认后创建条目。

批量导入会从发票 PDF 创建条目，并为 PDF 匹配同组 XML。文件夹中的付款截图和查验单会继续尝试匹配到刚创建的条目；归属明确时自动添加，需要确认时会要求手动选择。

### 拖拽导入

拖拽位置会影响文件用途：

- 拖到主界面空白处：作为一组新文件读取。发票会创建条目，其他材料会尝试匹配现有条目。
- 拖到某张发票卡片：直接把文件添加到该条目。
- 拖到详情中的材料区域：添加到当前条目的对应材料分组。

一次拖入 PDF、XML、付款截图和查验单时，Tidoc 会先识别文件类型，再完成创建和匹配。

### 粘贴导入

先在 Finder 或资源管理器中复制文件，再回到 Tidoc 主界面粘贴。处理方式与拖到主界面空白处相同。

### 使用「新建」

「新建」适合处理识别结果需要人工补充的单张发票。可以上传发票 PDF 和 XML，检查识别字段，再创建条目。

### 导入 XML

XML 与对应发票 PDF 同组导入。XML 可以提高发票号码、金额、税额和明细的准确度，PDF 用于创建条目和保留原票。

### 重复发票

Tidoc 会在全库中检查发票号码和发票文件内容。发现已有发票时，会显示原条目的报账人和基本信息，方便定位现有记录。

## 五、补齐和管理材料

### 从卡片添加

卡片上的材料按钮适合快速操作：

- 点击「付款」添加付款截图或填写实付金额。
- 点击「实物」添加一张或多张实物图。
- 点击「查验」进入在线查验流程。
- 点击「详情」查看全部材料和字段。

右键材料按钮可以直接打开已有文件。再次点击材料按钮可以继续添加同类文件。

### 从详情添加

详情页适合集中整理：

1. 展开发票、付款截图、实物图或查验单分组。
2. 添加、替换或删除文件。
3. 为具体附件填写附件备注。
4. 填写条目备注和实际物资名称。
5. 核对实付金额与发票金额。

### 付款截图和实付金额

付款截图 OCR 默认开启。添加截图后，Tidoc 会读取截图中的付款金额：

- 识别结果与发票金额一致时，可以直接写入实付金额。
- 多张截图会显示各笔金额和合计。
- 多个条目的金额相同，或截图中有多个候选金额时，软件会让用户选择条目或确认金额。

「实付默认等于发票金额」默认开启。实际发生分笔付款、部分付款或金额调整时，在卡片或详情中填写真实实付金额。

### 在线查验并归档查验单

1. 点击卡片上的「查验」。
2. Tidoc 打开国家税务总局查验平台，并预填可用的发票信息。
3. 完成验证码和查验。
4. 在官网点击「打印」，通过系统打印窗口选择横向布局并另存为 PDF。
5. 把 PDF 保存到下载、桌面、文档或设置中的额外归档目录。
6. 等待约 1–2 秒，Tidoc 会识别发票号码并归入当前条目。

第一次查验生成的查验单通常包含更完整的查验信息，建议优先保存。已有查验单也可以从卡片或详情手动上传。

### 设置材料要求

打开「设置 → 扩展 → 材料要求」，可以分别设置以下内容是否计入齐备状态：

- 付款截图
- 实物图
- 查验单
- 实付金额

发票是每个条目的基础材料。默认要求付款截图、查验单和实付金额，实物图按实际报账流程启用。

## 六、核对识别结果

### 列表视图

主界面的状态视图用于分步骤处理条目：

- 全部：当前范围内的全部条目。
- 待补材料：还需要补充必需材料的条目。
- 识别提醒：发票字段、金额、明细、抬头或税号需要核对的条目。
- 已识别：已经保存阿里云 OCR 结果的条目。
- OCR 待确认：本地结果与阿里云结果存在待确认差异的条目。
- 已修改：实付金额与发票金额存在差异的条目。
- 齐备：材料要求和发票校验均已完成的条目。

严重问题会使用更醒目的状态显示。打开详情可以查看具体原因。

### 发票识别顺序

Tidoc 优先读取 XML；同组没有 XML 时，解析 PDF 文本。常见数电发票的分栏明细、折扣行和错位文本会在解析时整理。

以下情况通常会进入识别提醒：

- 发票号码、日期、销售方或金额缺失。
- 明细金额与价税合计无法闭合。
- 发票抬头超出已配置范围。
- 已配置抬头的购买方税号缺失或不匹配。
- 附件类型或发票归属需要确认。

### 重新识别

识别规则更新，或发票、付款截图被替换后，可以刷新识别结果：

1. 勾选一个或多个条目。
2. 点击批量工具条中的「重新识别」。
3. 选择发票、付款截图或两者。
4. 查看每个条目的处理结果。

已经由当前规则处理且文件内容相同的材料会跳过。这样可以直接对旧条目运行批量操作，把需要更新的部分集中刷新。

### 阿里云结果对比

阿里云 OCR 用于补齐本地遗漏，并提供第二份结果用于核对。云端返回的新内容会按字段显示：

- 本地字段为空时，可自动补齐部分安全字段。
- 本地与云端明细存在差异时，进入「OCR 待确认」。
- 详情页会显示本地值、云端值和采用状态。
- 用户可以逐项采用，也可以保留当前值。

规格型号用于参考；名称、单位、数量、金额和明细行数是主要核对项。

## 七、筛选、标签和批次

### 搜索和筛选

搜索框支持以下内容：

- 发票号码
- 销售方
- 金额
- 条目备注
- 物资名称

工具条可以直接按抬头、报账人和标签筛选。「高级」中还可以组合日期、金额、状态、查验情况、备注和付款截图数量。

状态视图、批次和筛选条件可以叠加。例如，先打开某个批次，再选择「待补材料」和报账人，可以集中处理这个人在该批次中的缺失材料。

### 选择多个条目

- 点击卡片或勾选框选择条目。
- 按住 `Shift` 点击可连续选择。
- `Cmd/Ctrl + A` 选择当前列表中的全部条目。
- `Esc` 清除当前选择。

选择后会显示批量操作工具条，可统一修改报账人、添加标签、加入批次、重新识别、导出、打印或删除。

### 使用标签

选中条目后点击标签操作，也可以按 `T`。标签支持批量添加和移除。删除一个标签只会移除分类标记，条目和材料仍会保留。

### 使用报账批次

1. 选中准备一起处理的条目。
2. 点击批次操作并创建新批次，或加入已有批次。
3. 点击左侧批次名称查看其中条目。
4. 点击批次右侧「⋯」编辑名称、填写批次备注或归档。

批次备注适合记录本批次的用途、提交要求和交接信息。批次中的单个条目还可以填写催办备注。

归档后的批次进入「已归档」工作面。需要继续处理时可以恢复到在办。删除批次只会删除这组组织关系；删除条目会同时删除该条目的附件，请在确认窗口中核对操作范围。

## 八、绑定包、导出和打印

### 导出 `.tidoc` 绑定包

1. 选中需要交接的条目。
2. 点击「导出」。
3. 勾选「绑定包」，填写导出名称。
4. 点击「开始导出」。

绑定包包含条目、附件、报账人和完整性校验信息。阿里云识别结果与“已识别 / 待确认”状态也会一起保存。

「设置 → 偏好」可以控制绑定包是否包含：

- 条目备注
- 附件备注和备注修改记录
- 条目标签

### 导入 `.tidoc` 绑定包

可以通过三种方式进入导入预览：

- 点击主界面顶部的「导入包」。
- 把一个 `.tidoc` 文件拖入或粘贴到 Tidoc。
- 在系统文件管理器中双击 `.tidoc` 文件。

一次处理一个绑定包。预览页面会显示完整性状态和包内条目，并提供以下调整：

- 修改每组条目的报账人和审核人。
- 给全部新条目追加标签。
- 加入已有批次、创建新批次或暂时留在批次外。

导入时会识别全库中的重复发票，并在结果中列出跳过项。确认导入后，条目和附件会一起写入本机数据目录。

### 导出总览和附件

导出窗口还可以生成：

- 总览 Excel：汇总发票字段、金额、报账人、状态和备注。
- 附件整理包：按统一名称整理选中条目的材料并生成清单。

文件保存在导出目录。可以在导出完成窗口或「设置 → 数据位置」中打开该目录。

### 安装打印导出组件

第一次点击「打印」时，如果组件尚未安装，按弹窗提示安装。也可以前往「设置 → 组件与更新 → 软件与组件 → 管理」安装或修复。

### 生成打印件

1. 选中需要打印的条目。
2. 点击「打印」。
3. 选择合并方式和需要生成的 Word 文档。
4. 点击「生成打印件」。

默认方式按条目合并发票、付款截图和查验单。也可以按材料类型分别导出。生成结果按发票抬头分文件夹保存。

生成报账说明或验收单前，在「设置 → 数据位置 → 收款信息」填写姓名、学号、电话、开户行和卡号。当前聚焦某个批次时，已保存的批次备注会自动带入打印设置。

## 九、使用阿里云 OCR

阿里云 OCR 是可选的付费识别功能。它适合补齐规格、单位、数量等本地解析遗漏，并提供云端结果用于比对。普通导入、材料整理和打印流程可以直接使用本地识别结果。

### 1. 开通 OCR 服务

1. 登录阿里云并完成账号要求的实名认证。
2. 打开[增值税发票识别产品页](https://ai.aliyun.com/ocr/invoice)。
3. 按页面提示开通文字识别 OCR 和增值税发票识别服务。
4. 在[OCR 控制台](https://ocr.console.aliyun.com/overview)确认服务状态。

Tidoc 调用的是阿里云 `RecognizeInvoice` 接口。接口说明见[阿里云 RecognizeInvoice 文档](https://help.aliyun.com/zh/ocr/developer-reference/api-ocr-api-2021-07-07-recognizeinvoice)。

### 2. 创建专用 RAM 用户

为 Tidoc 单独创建一个 RAM 用户，可以把权限限制在 OCR 范围内：

1. 打开[RAM 控制台](https://ram.console.aliyun.com/)，进入「身份管理 → 用户」。
2. 点击「创建用户」，登录名称可填写 `tidoc-ocr`。
3. 创建后进入该用户详情页。
4. 在「权限管理」中新增授权，搜索并选择 `AliyunOCRFullAccess`。

`AliyunOCRFullAccess` 是阿里云提供的 OCR 系统策略，权限范围是文字识别 OCR 产品。可查看[策略说明](https://help.aliyun.com/zh/ram/developer-reference/aliyunocrfullaccess)和[创建 RAM 用户说明](https://help.aliyun.com/zh/ram/user-guide/create-a-ram-user)。

### 3. 创建 AccessKey

1. 在 `tidoc-ocr` 用户详情页打开「凭证管理」。
2. 在 AccessKey 区域点击「创建 AccessKey」。
3. 按页面提示完成安全验证。
4. 保存 AccessKey ID 和 AccessKey Secret。

AccessKey Secret 只在创建时显示一次。建议把它保存在可靠的密码管理工具中。详细步骤见[阿里云 AccessKey 文档](https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair)。

### 4. 在 Tidoc 中配置

1. 打开「设置 → 组件与更新 → 软件与组件 → 管理」。
2. 安装「OCR 识别组件」。
3. 返回设置中的「阿里云 OCR」。
4. 填写 AccessKey ID 和 AccessKey Secret，点击「保存」。

密钥保存后，设置页会显示脱敏后的 AccessKey ID 和本机累计调用次数。需要停用时，可以在同一位置清除密钥，并在阿里云 RAM 控制台中禁用或删除对应 AccessKey。

### 5. 发起云识别

1. 勾选一个或多个包含发票 PDF 的条目。
2. 点击批量工具条中的「云识别」。
3. 查看将调用的页数、跳过项和计费提示。
4. 确认后开始识别。
5. 在完成摘要中查看已补齐、待确认和失败的条目。

也可以在「识别提醒」视图使用批量建议，或在单个条目详情中点击「识别此发票」。

多页 PDF 会逐页调用并按页序合并。已有 XML 数据的条目会默认跳过；已有完整云识别结果的条目也会默认跳过，可以在确认页面中选择重新识别。

### 6. 计费和调用量

阿里云 OCR 按成功调用量计费，多页发票按实际调用页数计算。阿里云官网渠道通常按“免费额度、专用资源包、共享资源包、按量后付费”的顺序抵扣，具体额度和价格以阿里云当前页面为准。

- [OCR 产品计费说明](https://help.aliyun.com/zh/ocr/product-overview/product-billing/)
- [OCR 资源包说明](https://help.aliyun.com/zh/ocr/product-overview/resource-plans)
- [OCR 计费常见问题](https://help.aliyun.com/zh/ocr/support/billing-faq)

可以在 OCR 控制台查看调用量、资源包余量和账单。建议根据使用量设置余额或资源包告警。

### 7. 常见错误

- 提示组件缺失或损坏：在「软件与组件」中重新安装 OCR 识别组件。
- 提示密钥错误：重新核对 AccessKey ID 和 Secret，Secret 区分大小写。
- 提示无权限：确认 AccessKey 属于已授权 `AliyunOCRFullAccess` 的 RAM 用户。
- 提示服务未开通：回到 OCR 产品页开通增值税发票识别服务。
- 条目被跳过：检查条目是否包含发票 PDF，以及确认页面中的“跳过已有结果”选项。
- 结果需要确认：打开条目详情，在「阿里云识别」区域比较本地值和云端值。

## 十、设置、数据和更新

### 报账人和代填模式

在「设置 → 报账人」中管理姓名、审核人和默认报账人。

代填模式适合一台电脑整理多个人的材料。开启后，新建、批量导入和绑定包导入都可以选择报账人。

### 偏好

偏好中可以设置：

- 启动默认抬头
- 默认列表密度
- 浅色、深色或跟随系统的外观主题
- 付款截图 OCR
- 实付默认等于发票金额
- 绑定包包含备注
- 绑定包包含标签

首次使用可以保持默认值，熟悉流程后再按团队要求调整。

### 抬头与税号

在「设置 → 扩展」中维护学校或单位的发票抬头和购买方税号。识别提醒会按这份配置检查发票归属。

默认配置包含北京理工大学和北京理工大学教育基金会。其他学校、单位或项目可以直接添加自己的抬头和税号。

### 查验单设置

Tidoc 默认监测下载、桌面和文档目录中的新查验单。常用保存位置在其他目录时，可以设置一个额外归档目录。

「归档后清理原 PDF」开启后，查验单成功复制到条目时，原 PDF 会移到系统废纸篓或回收站。需要时可以从系统中恢复。

### 数据位置

「设置 → 数据位置」提供以下操作：

- 打开数据文件夹
- 打开导出目录
- 查看导出文件占用空间
- 清理拖拽中转文件和旧更新包
- 把数据迁移到新位置
- 恢复系统默认数据位置

数据迁移请使用软件中的迁移功能，让数据库和附件保持在同一数据目录中。

### 备份和恢复

备份步骤：

1. 退出 Tidoc。
2. 在「设置 → 数据位置」确认当前数据文件夹；也可以在退出前点击「打开文件夹」。
3. 复制整个数据文件夹到备份位置。

恢复步骤：

1. 退出 Tidoc。
2. 把当前数据文件夹移到另一个位置保留。
3. 把完整备份复制到原数据文件夹路径。
4. 启动 Tidoc，检查报账人、条目和附件。

数据库、附件、导出文件和组件目录应作为一个整体管理。软件中的数据迁移功能用于移动当前正在使用的数据目录，目标位置需要是空文件夹。

### 软件和组件更新

打开「设置 → 组件与更新 → 软件与组件 → 管理」，可以查看：

- Tidoc 核心版本
- 打印导出组件版本和完整性
- OCR 识别组件版本和完整性

核心更新会下载安装包并打开，退出 Tidoc 后按安装程序完成升级。打印和 OCR 组件会直接安装到本机数据目录，安装完成后状态会立即刷新。

「启动后检查更新」默认关闭。开启后，每 24 小时最多检查一次版本；下载和安装仍由用户确认。

## 十二、常见问题

### XML 没有创建条目

XML 与发票 PDF 配合使用。把 XML 和对应 PDF 放在同一批文件中重新导入即可。

### 付款截图没有自动绑定

常见原因包括截图金额识别为空、多个条目金额相同，或截图中出现多个付款数字。点击对应卡片的「付款」添加截图，或在系统提示中手动选择条目。

### 查验单没有自动归档

依次检查：

1. 查验单是否通过官网「打印」另存为 PDF。
2. 文件是否保存在下载、桌面、文档或设置的额外归档目录。
3. PDF 中是否包含可识别的发票号码。
4. 当前条目是否仍在等待本次查验。

也可以在卡片或详情中手动上传查验单。

### 软件升级后想重新处理旧发票

进入「识别提醒」或其他列表，选中条目并点击「重新识别」。软件会使用当前规则处理需要更新的文件。

### 打印按钮提示组件未安装

按弹窗提示安装，或打开「设置 → 组件与更新 → 软件与组件 → 管理」，安装打印导出组件。

### Word 中缺少姓名或银行卡信息

打开「设置 → 数据位置 → 收款信息」，补充姓名、学号、电话、开户行和卡号，再重新生成 Word。

### 导入绑定包时出现重复发票

导入结果会列出重复条目。可以根据发票号码和报账人回到主列表查找已有记录，再决定是否补充材料或备注。

### 删除批次后条目还在

批次用于组织条目。删除批次会保留条目和材料。需要删除发票记录时，请使用条目删除功能并确认范围。

### 从文件管理器双击 `.tidoc` 后图标没有刷新

先确认已经安装当前版本 Tidoc。Windows 可以注销并重新登录，或重启资源管理器；macOS 可以重新打开 Finder。系统更新文件关联缓存后会显示新图标。

## 十三、数据、网络和安全说明

这一节用于说明软件运行方式，日常使用可以按需查阅。

### 本机数据

Tidoc 的数据库、附件和设置保存在本机数据目录。主界面通过本地桌面窗口运行，日常整理无需启动浏览器服务。

删除条目时，对应附件会一起删除。删除批次、标签或筛选条件只改变组织方式。

### 网络访问

以下操作会使用网络：

- 打开国家税务总局查验平台
- 发起阿里云 OCR 识别
- 打开官网、GitHub、视频说明等外部链接
- 检查、下载或安装软件和组件更新

开启「启动后检查更新」后，软件按设置周期读取版本信息。其他整理操作在本机完成。

### AccessKey

阿里云 AccessKey 保存在本机数据中，导出的 `.tidoc` 绑定包不会携带密钥。绑定包导入后使用接收方电脑上的 OCR 配置。

建议为 Tidoc 使用独立 RAM 用户和独立 AccessKey。更换电脑或停止使用时，可在阿里云 RAM 控制台禁用旧 AccessKey。

### 绑定包完整性

`.tidoc` 绑定包带有 HMAC 完整性校验，用于发现文件在传输后的缺失或改动。绑定包中的发票、付款截图和个人信息仍是可读取的业务材料，传输和保存时应使用团队认可的安全方式。

### 识别数据

阿里云原始响应、解析结果、待确认状态和采用记录会保存在条目中，并随绑定包迁移。查看已经保存的结果不会产生新的 OCR 调用；重新发起识别会形成新的调用。
