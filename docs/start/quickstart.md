# 快速入门

用五步走完一遍从导入到导出的完整流程：选择方案与报账人、导入发票、补齐材料、核对、建立批次并导出。

不熟悉「条目」「材料」「批次」这些词时，可以先翻阅[基本概念](/guide/concepts)。

## 1. 选择方案并创建报账人

首次打开 Tidoc 时：

1. 选择日常使用的报账方案：「通用报账」或「BITFSAE 车队报账」；团队给了方案文件的，点「导入报账方案」。
2. 创建报账人，姓名填写发票的实际归属人。
3. 需要替多人整理材料时继续添加；添加第二位后，软件自动开启代填模式，新建和导入时都可以选择归属人。

报账人信息之后可以在「设置 → 报账人 → 管理」里随时调整。

## 2. 导入发票

点击主界面右上角「导入发票」，选择一张或多张发票的 PDF、XML，也可以直接选择整个文件夹。同一张发票的 XML 和 PDF 一起选，软件会自动配对，优先读取 XML 里的结构化数据。

在弹出的「确认导入」窗口里核对识别结果，选择报账人和报账批次，点击「创建选中条目」完成导入。

![导入预览](/images/import-preview.png)

也可以把文件直接拖进窗口，或在访达/文件资源管理器中复制后在软件里按 `Cmd/Ctrl + V` 粘贴。详见[导入发票](/guide/import)。

## 3. 补齐材料

在发票卡片右侧的快捷按钮上添加材料，并确认实付金额：

- 「付款」：添加付款截图或核对实付金额。
- 「实物」：添加采购实物照片。
- 「查验」：打开全国增值税发票查验平台，查验并自动保存查验单。
- 「详情」：打开条目详情，查看全部材料和明细。

材料文件也可以直接拖到卡片上。详见[补齐材料](/guide/materials)。

![卡片上的材料按钮](/images/card-actions.png)

## 4. 核对识别与提醒

依次查看「待补材料」和「识别提醒」两个视图，逐项处理未决事项：

- 「待补材料」：查看还缺必需材料的条目，补齐附件。
- 「识别提醒」：核对金额差额、明细或抬头税号，打开详情核对修改。

材料补齐、提醒处理完的条目会自动进入「齐备」视图。详见[核对识别结果](/guide/check)。

![状态视图](/images/status-views.png)

## 5. 建立批次并导出

勾选本次准备一起提交的条目，建立报账批次，再按交付方式选择导出：

- **交接给别人**：导出 `.tidoc` 绑定包，交给其他人整包导入继续整理。
- **电子归档**：导出总览 Excel 或规范命名的附件整理包。
- **打印报账**：生成材料拼接 PDF 和方案规定的 Word 审批单（第一次点击「打印」时按提示安装「打印导出组件」即可）。

详见[筛选、标签与批次](/guide/organize)与[导出、打印与交接](/guide/export)。

## 遇到问题与反馈渠道

- **查阅常见解答**：遇到问题先看[常见问题](/faq)；熟悉之后可以用[快捷操作](/guide/shortcuts)加快整理。
- **提交问题发票样本**：发票版式千差万别，如果遇到本地识别不准、金额算不对或漏掉明细的发票，欢迎将脱敏后的发票文件发送至邮箱 `info@bitfsae.com`，我们会持续补充样本进行测试与改进。
- **Issue 与交流**：有任何疑问或改进建议，欢迎在 [GitHub 提交 Issue 或 PR](https://github.com/BITFSAE/tidoc/issues)。
