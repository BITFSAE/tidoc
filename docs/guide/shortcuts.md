# 省时间的操作

整理报账材料时，花时间最多的是找文件和一张张点开。下面的操作按节省时间的多少排列，前面的先用上。键盘快捷键见[键盘快捷键](/guide/keyboard)。

## 拖放和粘贴文件

把文件拖进窗口，或者先在访达、文件资源管理器里复制，再回到 Tidoc 按 `Cmd/Ctrl + V`。落点不同，文件的用途不同：

| 操作 | 效果 |
| --- | --- |
| 把文件拖到主界面空白处 | 导入发票 PDF、XML 或 `.tidoc` 绑定包，其他材料会尝试匹配现有条目 |
| 把文件拖到某张卡片上 | 添加到该条目的材料，拖动时只有这张卡片高亮。图片按付款截图添加，实物图用卡片上的「实物」按钮 |
| 在主界面粘贴 | 与拖到空白处相同 |
| 在条目详情里粘贴 | 材料直接归入这个条目，图片按付款截图添加 |
| 把商家给的取票二维码图片拖进窗口，或截图后粘贴 | 联网取回发票的 PDF 和 XML，见[导入发票](/guide/import#用取票二维码导入) |
| 把团队管理员给的 `.tidoc-preset` 方案文件拖入窗口，或复制后粘贴 | 打开「导入报账方案」窗口，见[安装团队方案文件](/guide/schemes#安装团队方案文件) |

一次可以拖入或粘贴多张发票、付款截图和查验单，Tidoc 先识别文件类型再分别处理。各种落点的细节和无法匹配时的处理见[导入发票](/guide/import)。

`.tidoc` 绑定包和 `.tidoc-preset` 方案文件各自要单独放入，一次一个，不要和发票或其他文件一起拖。它们放在卡片或条目详情上，也是打开导入窗口，不会加入那个条目。

## 双击 `.tidoc` 文件打开

收到别人发来的 `.tidoc` [绑定包](/guide/concepts)后，在访达或文件资源管理器里直接双击，Tidoc 会启动并显示导入预览，不用先打开软件再点「导入包」。导入前需要已经创建报账人，预览里的各项设置见[导入绑定包](/guide/export#导入绑定包)。

Tidoc 已经在运行时，双击的文件会交给现有窗口。再次打开 Tidoc 本身，也只会回到已有窗口，不会出现第二个窗口。

Windows 上由安装器设置 `.tidoc` 的图标和打开方式。双击后图标没有变化时，见[常见问题](/faq)。

## 右键菜单

右键点击卡片，打开条目菜单。菜单包含「打开详情」「填写实付金额」「添加付款截图」「在线查验」「上传已有查验单」「添加发票 PDF」「编辑条目备注」「打标签」「批次」和「删除条目」。安装 OCR 识别组件，或保存了付款截图 AI 识别的 Key 后，多出「云识别」；在某个批次里查看时，「批次」换成「移出当前批次」，并多出「批次催办备注」。

卡片上的「发票」「付款」「查验」「实物」也可以右键：直接打开该条目已有的对应文件。点击这些按钮，则继续添加对应材料。

## 点卡片上的徽标

卡片标题行里的徽标可以直接点击：

| 徽标 | 点击后 |
| --- | --- |
| 报账人姓名 | 打开「修改报账人」窗口，改这个条目的报账人。有多位报账人、且没有按报账人筛选时才显示 |
| 批次名称，或灰色的「批次」 | 调整这个条目的批次，见[移动条目](/guide/organize#移动条目) |
| 「OCR」「已识别」 | 打开详情，查看阿里云 OCR 的识别结果 |

鼠标停在「识别提醒」等徽标上，可以直接看到原因，见[核对识别结果](/guide/check)。

## 批量处理

先选中多张卡片：点击卡片，`Shift` + 点击连续选择，或者用 `Cmd/Ctrl + A` 全选当前列表。选中后，批量工具条里的「批次」「标签」「报账人」「重新识别」「云识别」（安装 OCR 识别组件或保存付款截图 AI 识别的 Key 后显示）「汇总」「导出」「打印」「删除」作用于所有已选条目。

为已选条目批量填写报账信息，例如采购用途、存放地点：右键点击批量工具条里的「标签」，打开「批量填写报账信息」窗口，选一个字段，填写后点「保存到所选条目」。窗口里列出所选条目都有的字段；所选条目使用不同方案时，没有共有的字段可选。这个入口在右键里，左键点「标签」打开的是添加和移除标签的窗口。

## Windows 上看图

核对付款截图和实物照片时，要把图片一张张点开看。Windows 用户可以用[果核看图](https://pic.ghxi.com/zh/)作为看图软件。官网介绍它支持 JPG、PNG、HEIC、WebP 等常见格式，要求 Windows 10 及以上的 64 位系统，目前只有 Windows 版。

果核看图是第三方软件，与 Tidoc 没有从属关系，Tidoc 的功能也不依赖它。下载、安装和使用方式以对方官网为准。
