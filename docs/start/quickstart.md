# 快速入门

用五步走完一遍：选择方案、导入发票、补齐材料、核对、整理并导出。

不熟悉「条目」「材料」「批次」这些词时，先看[基本概念](/guide/concepts)。

::: tip 操作演示视频
两分钟的 [Bilibili 操作演示视频（BV1XN3q69EPi）](https://www.bilibili.com/video/BV1XN3q69EPi/)演示了从导入发票、补齐材料、核对提醒到批次导出的流程。
:::

## 1. 选择方案并创建报账人

首次打开 Tidoc 时：

1. BITFSAE 车队队员选「BITFSAE 车队报账」，之后不用再改方案。其他团队选「通用报账」；团队给了方案文件的，点「导入报账方案」。
2. 创建报账人，姓名填写发票的实际归属人。
3. 多人报账时继续添加。添加第二位后，新建和导入时都可以选择归属。

报账人之后可以在「设置 → 报账人 → 管理」里修改。方案怎么选、以后怎么换，见[报账方案](/guide/schemes)。

## 2. 导入发票

把发票的 PDF、XML 直接拖进窗口，或在 Finder、资源管理器中复制后在软件里粘贴。要选择整个文件夹，点击右上角「导入发票」。同一张发票的 XML 和 PDF 一起导入，软件会自动配对，优先使用 XML 里的数据。

在预览里检查识别结果，选择报账人和报账批次，确认后创建条目。

![导入预览](/images/import-preview.png)

详见[导入发票](/guide/import)。

## 3. 补齐材料

在发票卡片上添加材料，并确认实付金额：

- 「发票」：补充发票 PDF，例如先导入了 XML 的条目。
- 「实付」：填写或修改实付金额。
- 「付款」：添加付款截图。
- 「实物」：添加实物图。内置方案在条目还没有实物图时，卡片上不显示这个按钮，点「详情」，在「实物图」分组里添加。
- 「查验」：在线查验发票，保存查验单。
- 「详情」：查看全部材料和字段。

材料也可以直接拖到卡片上。详见[补齐材料](/guide/materials)。

![卡片上的材料按钮](/images/card-actions.png)

## 4. 核对

依次查看「待补材料」和「识别提醒」两个视图，打开详情核对字段、明细和备注。材料补齐、提醒处理完的条目会进入「齐备」。详见[核对识别结果](/guide/check)。

![状态视图](/images/status-views.png)

## 5. 整理并导出

勾选要一起提交的条目，建立报账批次，再按交付方式选择：

- 导出 `.tidoc` 绑定包，交给别人继续整理。
- 导出总览 Excel 或附件整理包。
- 生成材料 PDF 和方案规定的 Word 文档。这一步需要先安装打印导出组件，在「设置 → 组件与更新 → 软件与组件 → 管理」里安装，见[软件和组件更新](/update/)。

详见[筛选、标签与批次](/guide/organize)和[导出、打印与交接](/guide/export)。
