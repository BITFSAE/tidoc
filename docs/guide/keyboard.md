# 键盘快捷键

本页列出键盘操作。拖放、粘贴和右键菜单见[省时间的操作](/guide/shortcuts)。`Cmd` 用于 macOS，`Ctrl` 用于 Windows。

在主界面按 `?`，或点「设置」底部的「快捷键」，可以打开常用快捷键的速查窗口。部分按钮的悬停提示和条目右键菜单里也写出了对应的按键。

::: tip 提示
`/`、`N`、`T`、`?` 和 `Cmd/Ctrl + A` 在主界面的列表里使用。光标在输入框里，或者有弹窗打开时，这些按键不触发列表操作。
:::

## 选择

| 操作 | 效果 |
| --- | --- |
| 点击卡片 | 选中或取消选中该条目 |
| `Shift` + 点击 | 从上次选中的卡片连续选到这一张 |
| 方向键，或 `Tab` / `Shift` + `Tab` | 在卡片之间移动。`Tab` 往下一张，`Shift` + `Tab` 回上一张；走到列表头尾后再按，就离开列表 |
| `Shift` + 方向键 | 移动的同时连续选中 |
| `Home` / `End` | 跳到列表的第一张 / 最后一张 |
| `PageUp` / `PageDown` | 向上 / 向下跳 5 张 |
| 空格 | 选中或取消选中当前卡片，`Shift` + 空格连续选择 |
| 按分组浏览时，`Tab` 走到分组标题左侧的方框，按空格或 `Enter` | 选中或取消选中整组 |
| `Cmd/Ctrl + A` | 选择当前列表中的全部条目 |
| `Esc` | 有菜单时关闭菜单，有弹窗时关闭弹窗；否则清除当前选择。在输入框里退出输入 |

## 打开与搜索

| 操作 | 效果 |
| --- | --- |
| `Enter` | 打开当前卡片的详情 |
| `/` | 光标跳到搜索框，可搜索发票号、销售方、金额、备注和物资名称 |
| 搜索框里按 `↓` 或 `Enter` | 立即按输入的词搜索，光标落到结果列表的卡片上 |
| `N` | 新建条目 |
| `?` | 打开常用快捷键的速查窗口 |
| 菜单键，或 `Shift + F10` | 在键盘焦点所在的卡片上打开条目菜单 |
| 打印导出窗口刚打开时按 `Enter` | 按当前选择开始检查并生成 |

键盘打开菜单后，用 `↑` `↓` 选择，`Enter` 或空格执行，`Esc` 关闭，焦点回到原来的卡片。卡片上的「发票」「付款」「查验」等小按钮不在 `Tab` 顺序里，键盘上改用条目菜单或 `Enter` 打开的详情来添加材料。批次栏里每个批次右侧的「⋯」也能用 `Tab` 走到，`Enter` 打开它的菜单。菜单里有哪些项见[省时间的操作](/guide/shortcuts#右键菜单)。

## 标签

| 操作 | 效果 |
| --- | --- |
| `T` | 给已选条目添加或移除标签，需要先选中条目 |

## 详情里的行内编辑

在条目详情里点击「关键信息」的数值或「物品明细」的单元格，就能直接修改：

| 操作 | 效果 |
| --- | --- |
| `Enter` | 保存修改 |
| `Esc` | 放弃这次修改，恢复原值 |
| `Tab` / `Shift` + `Tab` | 保存当前单元格，并跳到「物品明细」的下一格 / 上一格继续编辑 |

## 弹窗

| 操作 | 效果 |
| --- | --- |
| `Enter` | 在单行输入框里按下，等同点击窗口右下角的主按钮（如「保存」「创建」）。确认类的小窗口直接按 `Enter` 也一样，危险操作（如删除）的窗口不会这样 |
| `Cmd/Ctrl + Enter` | 在多行的备注框里保存；备注框里单按 `Enter` 是换行 |
| `Esc` | 关闭弹窗；个别窗口（如报账方案）有未保存的修改时，会先询问 |
| `Tab` / `Shift` + `Tab` | 在弹窗内部循环，不会跳到后面的主界面 |

需要输入的弹窗（新建批次、编辑备注、填写实付金额等）打开后光标已经在输入框里，可以直接输入。
