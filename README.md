> 通用的报账凭证管理与整理工具。

tidoc 是一款跨平台桌面程序，以一张发票为工作单元，完成发票导入、材料补齐、识别提醒、筛选和批次整理，并导出可交换或打印的报账材料。适合个人、团队和社团使用。

- **界面**：PyWebView 原生窗口 + HTML/CSS/JS
- **核心**：Python，本地运行，不监听网络端口
- **数据**：SQLite + 本地附件仓库
- **交换**：带 HMAC 签名的 `.tidoc` 绑定包
- **打印**：可选独立组件，生成合并 PDF 与 Word
- **云识别**：可选阿里云 OCR 组件，用于补齐本地识别遗漏并比对结果（按量计费，自填密钥）

## 下载与安装

- [官网下载](https://www.bitfsae.com/)：在首页底部找到「报账软件」，页面会按系统推荐安装包。
- [GitHub Releases](https://github.com/totok22/tidoc/releases/latest)

- macOS：下载 `tidoc-core-macos-v{version}.dmg`，打开后把 Tidoc 拖入“应用程序”。
- Windows：下载 `tidoc-core-windows-v{version}.exe` 并按提示安装，默认安装到当前用户目录。

首次打开时，先创建报账人并填写姓名、审核人。随后可按实际报账要求完成三项设置：

1. 在「设置 → 扩展 → 抬头与税号」维护单位名称和购买方税号，并选择新建条目的默认抬头。
2. 在「设置 → 扩展」设置付款截图、实物图、查验单和实付金额的材料要求。
3. 在「设置 → 组件与更新」安装打印导出组件；需要阿里云识别时再安装 OCR 识别组件，并在「阿里云 OCR」填写 AccessKey。

生成报账说明或验收单 Word 时，可在「设置 → 数据位置」下方展开「收款信息」，维护姓名、学号、电话、开户行和卡号。

完整操作演示见 [Bilibili 使用说明视频](https://www.bilibili.com/video/BV1XN3q69EPi/)。

## 快速上手

### 1. 导入发票

点击右上角「导入发票」，可选择多个文件或整个文件夹。也可以把文件拖入窗口，或复制文件后在 Tidoc 中粘贴。

- 发票 PDF 用于创建条目并识别发票号码、日期、销售方、金额和明细。
- 发票 XML 与对应 PDF 一起导入时，会提供更完整、准确的结构化数据。
- 文件夹中混有多张 PDF、XML 和其他材料时，Tidoc 会批量创建条目并尝试自动匹配。
- 收到别人导出的 `.tidoc` 绑定包时，可点击「导入包」、拖入窗口或直接双击文件。

### 2. 补齐材料

每张发票会显示为一张卡片。卡片上的「付款」「实物」「查验」可直接添加材料，也可以打开详情集中整理。

- 把材料拖到对应卡片上，Tidoc 会结合文件类型、发票号和刚导入的条目自动归类。
- 右键材料按钮可打开已经上传的文件；右键卡片可编辑备注、添加材料、打标签或调整批次。点击卡片上的报账人和批次徽标，可直接修改归属。
- 付款截图支持本地金额识别，识别到多个候选金额时可手动选择实付金额。
- 点击「查验」可打开国家税务总局平台并预填发票信息。完成验证码后，在官网选择打印并另存为 PDF，Tidoc 会识别新文件并归入当前条目。

材料要求由「设置 → 扩展」控制。默认包含发票、付款截图、查验单和实付金额，实物图可按报账场景启用。

### 3. 核对条目

使用「待补材料」「识别提醒」「OCR 待确认」「齐备」几个视图依次处理条目：

- 「待补材料」集中显示还需要付款截图、查验单或实付金额的条目。
- 「识别提醒」用于核对金额、明细、抬头和购买方税号。
- 「OCR 待确认」展示本地结果与阿里云结果的差异，可在详情中逐项采用。
- 「齐备」表示材料要求和发票校验均已完成，适合进入批次或直接导出。

更换过发票或付款截图后，选中条目并点击「重新识别」，即可按当前规则刷新结果。详情中可填写实付金额、实际物资名称、条目备注和附件备注，修改记录会随条目保存。

### 4. 整理报账批次

勾选一张或多张卡片后，可以批量设置报账人、标签和报账批次。批次适合对应一次提交、一个项目或一组经费。

- 点击批次名称可查看该批次的全部条目。
- 点击批次右侧「⋯」可编辑名称、填写批次备注或归档。
- 「在办 / 已归档」用于切换当前工作面，归档批次也可以恢复后继续整理。
- 在某个批次中发起打印时，批次备注会自动带入打印设置。

### 5. 查找和筛选

搜索框支持发票号、销售方、金额、备注和物资名称。抬头、报账人、标签可直接筛选；「高级」中还可组合日期、金额、材料状态、查验状态、备注和付款截图数量。

常用视图和筛选条件可以一起使用。例如先进入「待补材料」，再选择某个报账人，就能集中处理这个人的缺失材料。

### 6. 导出和打印

选中条目后点击「导出」或「打印」：

- **绑定包**：生成 `.tidoc` 文件，包含条目、附件、报账人和校验信息，适合交给另一台电脑继续整理。
- **总览 Excel**：生成便于核对、统计和留档的条目清单。
- **附件整理包**：按统一名称整理发票和相关材料。
- **打印件**：按条目合并发票、付款截图和查验单，也可按材料类型分别输出。
- **Word 文档**：根据收款信息生成报账说明和验收单，并按发票抬头分开保存。

导出结果保存在「设置」中显示的导出目录。完成后可在结果窗口直接打开文件或所在文件夹。

## 绑定包协作

导入 `.tidoc` 绑定包时，会先展示完整性、条目、报账人和附件概况。确认页面支持调整报账人、审核人、标签及目标批次；已有发票会标记为重复并跳过。阿里云识别结果和待确认状态会随绑定包一起恢复。

在「设置 → 扩展」中可以选择绑定包是否携带条目备注、附件备注和标签。Windows 与 macOS 安装包均为 `.tidoc` 配置了文件图标，系统完成关联后可从文件管理器直接打开。

## 识别说明

- Tidoc 优先读取发票 XML，其次解析 PDF 文本，适配常见数电发票的分栏明细、折扣行和错位文本。
- 付款截图金额和查验单发票号可使用系统本地识别；识别结果仍可在详情中调整。
- 阿里云 OCR 是可选的付费识别方式，适合补齐规格、数量等字段，并提供第二份结果用于核对。多页发票按页调用，确认窗口会提前显示预计调用次数。
- 阿里云识别结果保存在条目中，可反复查看和比较；计费发生在主动发起识别时。
- 「识别提醒」反映发票内容校验，「材料齐备」反映报账材料进度，两者会分别显示。
- **报账人**表示发票归属，包含姓名和审核人；**收款信息**用于生成 Word。条目备注描述整张发票，附件备注描述某个具体文件，标签用于分类和筛选。

## 常用快捷操作

- `N`：新建条目
- `/`：聚焦搜索框
- `T`：给已选条目添加标签
- `Cmd/Ctrl + A`：选择当前列表中的全部条目
- `Shift + 点击`：连续选择多张卡片
- `Esc`：清除当前选择或关闭弹窗
- 方向键：在卡片之间移动；`Enter` 打开详情，空格选择卡片
- 右键卡片：打开常用操作菜单；右键材料按钮：打开已有材料

## 网络与更新

日常发票整理和材料管理在本机完成。打开税务查验、发起阿里云识别、访问外部链接以及检查或安装更新时会使用网络。

「启动后检查更新」默认关闭；开启后每 24 小时最多检查一次，下载和安装仍由用户确认。设置中的「软件与组件」会显示核心、打印导出组件和 OCR 识别组件的状态，也可以从这里安装、更新或修复组件。

阿里云识别使用用户填写的 AccessKey，密钥保存在本机数据中。每次识别前会显示预计调用页数和计费提示，方便确认本次操作。

## 开发

```bash
git clone https://github.com/totok22/tidoc.git
cd tidoc
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
pip install -r requirements-print.txt   # 可选：启用打印导出组件
pip install -r requirements-ocr.txt     # 可选：启用阿里云云识别组件

python -m tidoc                    # 启动应用
python -m tidoc --debug            # 打开 WebView 调试
pytest                             # 运行测试
```

从源码运行时优先使用当前工作区的 `tidoc_print` / `tidoc_ocr`；发布版只调用已安装并校验过的独立组件。

## 项目结构

```text
tidoc/            核心（pywebview + pypdf + Send2Trash）
├─ engine/        发票 XML / PDF 解析与金额校验
├─ db/            SQLite、附件仓库、报账人、条目和批次
├─ services/      导入、汇总、绑定包、导出、打印适配和更新
├─ web/           HTML/CSS/JS 前端
├─ api.py         PyWebView JS ↔ Python 桥
└─ app.py         应用入口
tidoc_print/      打印导出组件（可选，含 Word / PDF 重依赖）
tidoc_ocr/        OCR 识别组件（可选，含阿里云 SDK，只在用户点击时联网）
scripts/          构建、版本号注入和打包入口
icon/             方形母版及 Windows 圆角 / macOS 方形平台图标
tests/            pytest 测试
```
