# 设置与数据

点击主界面右上角的齿轮图标打开「设置」。右上角的书本图标和设置底部的「文档站」都会在浏览器里打开本文档站。本页说明报账人、偏好、查验单、数据位置、备份恢复，以及哪些操作会联网。

![设置](/images/settings.png)

「个人收款信息」「导出记录」位于设置顶部，见[导出、打印与交接](/guide/export)；「组件与更新」见[软件和组件更新](/update/)。设置底部的「使用提示」可以重新打开新手提示。

「开发者选项」默认收起，里面是日常整理用不到、需要单独配置的功能：「报账方案」（见[报账方案](/guide/schemes)）、「付款截图 AI 识别」（见下文）和「发票阿里云 OCR」（见[阿里云 OCR](/guide/aliyun-ocr)）。展开一次后，下次打开设置仍保持展开。

## 报账人与代填模式

报账人表示发票的归属人，详见[基本概念](/guide/concepts)。

1. 在「设置」的「报账人」一行点击「管理」，打开「报账人管理」。
2. 在「新增报账人」里填写姓名，再按方案要求填写审核人，点击「添加报账人」。
3. 已有的报账人可以「编辑」「设为默认」或「删除」。

姓名必填。审核人是否必填、是否放在高级选项里，由[报账方案](/guide/schemes)决定。

「代填模式」适合一台电脑整理多个人的材料。开启后，新建、批量导入和导入绑定包时都可以选择报账人。添加第二位报账人时，Tidoc 会自动开启代填模式，也可以在「设置」的「代填模式」里手动开关。

## 偏好

「设置 → 偏好」可以调整：

- 「启动默认抬头」：打开软件时默认聚焦哪个抬头分区。
- 「默认列表密度」：「标准」或「精简」。
- 「外观主题」：「跟随系统」「浅色」或「深色」。顶栏的月亮、太阳图标也可以快速切换。
- 「卡片显示创建时间」：在卡片上显示精确到分钟的创建时间，默认关闭。

新建默认抬头、实付初值，以及绑定包是否带出备注和标签，属于报账方案设置，在「设置 → 开发者选项 → 报账方案 → 管理」里修改。

## 付款截图 AI 识别

![付款截图 AI 设置](/images/payment-ai-settings.png)

在「设置 → 开发者选项 → 付款截图 AI 识别」里：

1. 在「服务商」中选择 DeepSeek Flash（推荐）、Qwen Flash 或其他兼容服务。
2. 在「API Key」中填入 Key，点击「保存」。还没有 Key 时，点「获取 Key」打开服务商的控制台申请。

保存后显示 Key 开头「sk-」之后的两位和末尾四位，例如 `sk-ab****90xy`，便于核对用的是哪一把。每个服务商的 Key 分开保存，切换服务商后显示并使用该服务商的 Key，切回来时原来的 Key 仍在。切到还没有保存 Key 的服务商时，「添加截图时自动识别」会关闭，保存 Key 后需要重新开启。Key 仅保存在本机，不随绑定包或报账方案导出。

使用 DeepSeek 时，点 Key 旁的「查询余额」可查看账户余额。只在点击时查询。

保存 Key 后可以随时手动识别：选中条目，点击「云识别」，勾选「付款截图 · AI」。「添加截图时自动识别」决定添加付款截图时是否自动上传识别，默认关闭；关闭后不会自动上传，手动识别不受影响。两种方式都按量计费。

「费用估算」显示每 100 张的估算，用过之后还显示累计调用次数和费用；点「官方价格」查看服务商的价格页。估算按本机已识别截图的平均用量计算，命中服务商缓存的部分按缓存价计；还没有识别过时按预设用量估算。以服务商账单为准。

展开「高级选项」可以修改：

- 「接口地址」「模型」：使用其他兼容服务时填写。改动即保存，不需要再点按钮。
- 「并发数量」：默认 32，遇到限流时调低。
- 「单价」：仅其他兼容服务需要，填写输入、输出单价后才能估算费用。
- 「识别提示词」：发给服务商的识别说明，可以修改，点「恢复默认」还原。提示词开头规定了返回的字段，修改时保留这部分，否则识别会失败。
- 「附加要求」：接在提示词末尾的额外要求，例如「需有付款时间」。恢复默认提示词时保留。

改了服务商、模型、提示词或附加要求后，已识别的截图要在「云识别」中重新识别才会按新设置判断。

识别后怎样填写实付、哪些情况会提醒，见[付款截图与实付金额](/guide/materials#付款截图与实付金额)。

## 查验单

Tidoc 默认监测下载、桌面和文档文件夹里新出现的查验单 PDF，用于[补齐材料](/guide/materials)。

- 「额外归档目录」：常用保存位置在其他文件夹时，点击「选择」再添加一个监测位置；点击「清除」恢复默认监测范围。
- 「归档后清理原 PDF」：开启后，查验单成功复制到条目时，原 PDF 会移到系统废纸篓或回收站，需要时可以从系统中恢复。

## 数据位置

「设置 → 数据位置」显示当前数据文件夹的路径，以及它是「系统默认位置」还是「自定义位置」。条目数据、附件、导出文件和组件都保存在这个文件夹里。

- 「打开文件夹」：在文件管理器中打开数据文件夹。
- 「打开导出目录」：打开导出文件所在位置，按钮上同时显示导出文件占用的空间。
- 「清理临时文件」：清理拖拽中转文件和旧的更新包，按钮上显示可释放的空间。
- 「清理旧备份」：升级软件时，Tidoc 会先保存一份升级前的数据副本。副本超过 2 份时出现这个按钮，点击后删除较早的副本，保留较新的 2 份，删除后不能恢复。

展开「高级数据维护」可以移动数据：

- 「迁移到新位置…」：选择一个空文件夹，把当前数据迁移过去。迁移过程中请勿关闭软件。
- 「恢复默认位置」：数据位于自定义位置时出现，把数据迁回系统默认位置。

移动数据请使用这里的迁移功能，让条目数据和附件始终保存在同一个数据文件夹里。

## 备份与恢复

数据文件夹里的条目数据、附件、导出文件和组件需要作为一个整体备份和恢复。

备份：

1. 退出 Tidoc。
2. 在「设置 → 数据位置」确认当前数据文件夹，也可以在退出前点击「打开文件夹」。
3. 把整个数据文件夹复制到备份位置。

恢复：

1. 退出 Tidoc。
2. 把当前的数据文件夹移到别处保留。
3. 把完整的备份复制到原数据文件夹的路径。
4. 启动 Tidoc，检查报账人、条目和附件。

::: tip 提示
只想带走一部分条目时，可以导出 `.tidoc` 绑定包，在另一台电脑导入，见[导出、打印与交接](/guide/export)。
:::

## 本机数据与联网

Tidoc 的条目、附件和设置都保存在本机数据文件夹里，日常整理不需要网络。删除条目时，它的附件会一起删除。

以下操作会联网：

- 打开国家税务总局查验平台做在线查验。
- 把商家给的取票二维码图片拖入或粘贴进软件，或在失败结果里点击「重试」时，访问二维码指向的国家税务总局电子发票服务平台地址，下载这张发票的 PDF 和 XML。见[导入发票](/guide/import#用取票二维码导入)。
- 发起阿里云 OCR 识别（点击「云识别」时）。
- 付款截图 AI 识别：在「云识别」中手动识别付款截图时，或开启「添加截图时自动识别」后添加截图时，上传至设置中选择的服务商。已有有效缓存时直接复用。
- 点击「查询余额」时，向 DeepSeek 查询账户余额。
- 打开使用文档、官网、GitHub、视频说明等外部链接。
- 检查、下载或安装软件和组件更新。

更新的联网方式见[软件和组件更新](/update/)。团队方案文件从本地导入，Tidoc 不会在后台下载团队规则。

阿里云 AccessKey 只保存在本机，导出的绑定包不会携带它；绑定包导入后，使用接收方电脑上的 OCR 配置。建议为 Tidoc 单独创建 RAM 用户和 AccessKey，更换电脑或不再使用时，在阿里云控制台禁用旧的 AccessKey，见[阿里云 OCR](/guide/aliyun-ocr)。
