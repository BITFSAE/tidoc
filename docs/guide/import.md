# 导入发票

发票可以拖拽、粘贴、用取票二维码取回、批量导入或手动新建。每张发票生成一个[条目](/guide/concepts)，导入时可以同时指定报账人和[报账批次](/guide/concepts)。

把文件拖进窗口，或在文件夹里复制后粘贴，不用先点按钮。发票在手机上时，先把文件保存到电脑。要一次选整个文件夹，用批量导入。

## 拖拽导入

把文件拖进 Tidoc 窗口。落点不同，文件的用途不同：

- 拖到主界面空白处：当作一组新文件读取。发票 PDF 和 XML 打开「确认导入」窗口；[绑定包](/guide/concepts)（`.tidoc` 文件）打开导入预览；付款截图和查验单尝试匹配已有条目，无法匹配的在「绑定材料」窗口里逐份选择条目和类型，这里可以选「实物图」。
- 拖到某张发票卡片上：把文件添加到这张卡片的条目。图片按付款截图添加，PDF 按内容分为查验单或发票 PDF；实物图用卡片上的「实物」按钮。拖入的发票文件必须属于这张发票，否则提示「这张发票不属于当前条目」。`.tidoc` 绑定包和 `.tidoc-preset` 方案文件不会加入条目，仍打开各自的导入窗口。
- 拖到详情里的「报账材料」区域：添加到当前条目，规则与拖到卡片上相同；实物图在对应分组里用「＋ 添加」。

「确认导入」窗口的用法见下面「批量导入多张发票」一节。

一次拖入发票、付款截图和查验单时，Tidoc 先识别文件类型，再创建条目。查验单按发票号码绑定；付款截图在开启「添加截图时自动识别」后按金额匹配。无法确定归属的材料，会弹出「绑定材料」窗口，让你逐份选择条目。

拖动时，窗口底部的提示说明松手后的用途：空白处出现虚线框，移到卡片上时只有目标卡片高亮。已经打开详情等窗口时不显示这条提示，详情里的材料区域自带高亮。

## 粘贴导入

先在访达或文件资源管理器中复制文件，再回到 Tidoc 按 `Cmd/Ctrl + V`：

- 在主界面粘贴发票：打开「确认导入」窗口，可以选择报账人和报账批次。
- 先打开某个条目的详情，再粘贴付款截图（图片）、查验单，或这张发票的 PDF、XML：材料直接加入当前条目，详情随即显示处理结果。图片一律按付款截图添加，实物图在详情的对应分组里用「＋ 添加」；粘贴的发票文件必须属于这张发票。
- 在主界面粘贴其他材料：处理方式与拖到主界面空白处相同。

## 用取票二维码导入

商家有时只给一个取票二维码，而不是发票文件。这种二维码指向国家税务总局电子发票服务平台，Tidoc 可以直接取回发票：

1. 把二维码图片拖进窗口空白处，或截图后按 `Cmd/Ctrl + V` 粘贴。支持 PNG、JPG、WebP、BMP。一次可以放多张，同一张发票的重复图片只取一次。
2. Tidoc 读出二维码，联网到二维码指向的税务平台地址，同时下载这张发票的 PDF 和 XML。提示条里会显示进度，可以点「取消」。
3. 取回后打开「确认导入」窗口，和导入发票文件一样检查、选择报账人和报账批次。

只有这一步会联网。图片里没有取票二维码时，Tidoc 把它当作付款截图或实物图，按原来的方式处理。把图片拖到某张卡片上，或在条目详情里粘贴，一律当作材料，不会取票。

使用时注意：

- 只能识别税务平台的取票二维码。发票票面上的二维码只含发票信息，不含下载地址，不能用来取票。
- 这个功能调用税务平台网页使用的接口，不是公开的服务。平台改版、链接失效、网络不通或平台拒绝时，Tidoc 会写明原因。网络中途断开时，Tidoc 会自动重试；仍然失败可以点「重试」继续取回并进入「确认导入」，也可以点「在浏览器中打开」下载 PDF 和 XML，再把文件拖进软件。
- 点「取消」后停止后续取票，并尝试中断正在下载的文件；已经发到平台的请求无法撤回。正在连接平台时，可能要等连接超时才停止，迟到的文件不会继续导入。
- 目前在深圳、广东、湖北的取票链接上验证过，其他地区没有验证。
- 多数地区的平台几秒完成。深圳等平台生成 PDF 较慢，一张发票可能要几十秒，Tidoc 同时下载 PDF 和 XML。
- Windows 上的 HEIC 图片，以及所有平台的 AVIF 图片，识别不了二维码，请截图后再试，或转成 JPG、PNG。

## 批量导入多张发票

1. 点击右上角「导入发票」。
2. 在「批量导入」窗口选择「选择文件夹」或「多选发票文件」。选择文件夹时，会扫描其中的发票 PDF 和 XML，包括子文件夹。
3. 在「确认导入」窗口检查识别出的发票分组，不需要导入的分组取消勾选「导入」。
4. 选择「报账人」和「报账批次」。没有合适的报账人，点「新建报账人」；批次下拉框里选「＋ 新建批次…」并输入名称，可以顺手建立新批次。
5. 点击「创建选中条目」。

![确认导入窗口，列出识别出的发票分组](/images/import-preview.png)

「确认导入」窗口的分组规则如下：

- 每个发票 PDF 创建一个条目。同一张发票的 XML 自动配对，不需要改文件名：先按发票号码配对，再按相近的文件名配对。读取发票内容时优先使用 XML。
- 有发票号码但没有 PDF 的 XML 单独成组，可以先导入，见下文「先导入 XML，之后补 PDF」。
- 读不出发票号码的 XML 列在「未匹配 XML」，检查文件后重试。
- 付款截图、查验单、重复的发票文件和含多张发票的 PDF 列在「未参与批量」，不会创建条目。含多张发票的 PDF 需要先拆成单张。
- 某个分组创建失败时，该分组在窗口里标红并写明原因，其余分组正常创建。

付款截图和查验单在条目里添加，见[补齐材料](/guide/materials)；也可以和发票一起拖入，见上文「拖拽导入」。

## 新建单张发票

适合只有一张发票，或想逐项上传材料的情况。

1. 点击右上角「新建」，或按 `N`。
2. 在「新建报账条目」窗口选择抬头和报账人。
3. 上传「发票 PDF」和「发票 XML」，建议两个都传，识别更准。下面的材料卡按当前报账方案显示，例如「付款截图」「实物图」「查验单」，名称和顺序来自方案，可以都不传，之后再补；方案里没有配置或设为隐藏的材料不显示。
4. 选好 PDF 或 XML 后，窗口显示识别结果。核对发票号码、日期、销售方、购买方抬头、价税合计和明细条数。
5. 点击「保存」。

## 先导入 XML，之后补 PDF

XML 提供发票号码、金额、税额和明细，PDF 保留票面。两者可以分开到达：

1. 先用「导入发票」或「新建」导入 XML。「导入发票」的预览里，只有 XML 的分组会提示「先导入 XML；打印票面前补充发票 PDF。」
2. 拿到 PDF 后，点卡片上的「发票」选择 PDF，或把 PDF 拖到这张卡片上。

需要打印票面的输出要求有 PDF。缺 PDF 时，打印前的检查会提醒，补齐后再生成，见[导出、打印与交接](/guide/export)。

## 重复发票

Tidoc 在所有已有条目中检查重复，包括所有报账人，以及在办批次、已归档批次和未进批次的条目。先比对发票号码，没有命中时再比对发票文件内容。

命中已有发票时，该分组不会创建。窗口显示「未创建」、原条目的销售方、报账人和批次名称；已归档的批次标明「已归档」，没有批次则显示「未进批次」。点击「查看已有条目」打开详情，补充材料或修改归属。关闭详情后可继续处理其余导入分组。

改报账人或批次不能绕过查重。用「新建」保存时同样会提示原条目的位置。同一次导入里发票号码相同的两个 PDF，第二个列入「未参与批量」。

## 常见问题

### 从微信拖入时提示「无法读取」怎么办

微信等应用的缓存文件受系统保护，Tidoc 读不到。先在微信里把文件另存到桌面或「下载」文件夹，再从那里拖入。

### XML 没有出现在导入预览里怎么办

批量导入只列出能读出发票号码的独立 XML。检查步骤见[常见问题](/faq#xml-没有进入批量导入预览怎么办)。
