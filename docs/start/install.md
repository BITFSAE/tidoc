# 下载与安装

Tidoc 提供 Windows 与 macOS 平台的安装包，安装后即可离线使用。

## 下载渠道

可通过以下任一渠道获取官方安装包：

- **官网**：访问 [www.bitfsae.com](https://www.bitfsae.com/)，在页面底部点击「报账软件」。
- **GitHub Releases**：访问 [Releases 页面](https://github.com/BITFSAE/tidoc/releases/latest)，在最新发布版本列表中下载对应系统的安装包。

安装包命名规则如下（`{version}` 为具体版本号）：

| 系统平台 | 安装包文件名 |
| --- | --- |
| Windows | `tidoc-core-windows-v{version}.exe` |
| macOS | `tidoc-core-macos-v{version}.dmg` |

## Windows 安装

1. 双击运行 `.exe` 安装程序，跟随向导完成安装。
2. 安装完成后，在「开始」菜单中启动 Tidoc。

程序默认安装至当前用户目录，通常无需管理员权限。安装程序会自动注册 `.tidoc` 绑定包的文件关联与图标。

若下载或启动时出现系统安全提示，确认安装包来源可靠后按以下方式放行：

1. Edge 下载提示：选择「保留」或「仍要保留」。
2. SmartScreen 拦截窗口：点击「更多信息 → 仍要运行」。

::: tip 提示
受企业域控或设备策略管理的计算机若限制运行未签名安装包，请联系设备管理员协助处理。
:::

## macOS 安装

1. 双击打开 `.dmg` 镜像，将 Tidoc 图标拖入「应用程序（Applications）」。
2. 在「应用程序」中启动 Tidoc。

首次启动若提示无法验证开发者：在访达（Finder）中右键点击 Tidoc 图标，选择「打开」，并在确认弹窗中再次点击「打开」；亦可前往「系统设置 → 隐私与安全性」，在安全性拦截提示旁点击「仍要打开」。

## 首次启动配置

首次运行需完成两项基础配置：

1. **选择报账方案**：选择日常适用的方案（「通用报账」或「BITFSAE 车队报账」）；若团队提供了专属方案包，点击「导入报账方案」。方案可在设置中随时切换，已录入条目不受影响。
2. **创建报账人**：填写实际报账人姓名。

配置完成后即可进入主工作台。后续操作可参考[快速入门](/start/quickstart)。

## 版本更新机制

软件启动后会自动检查版本更新。若检测到新版本，主界面顶栏将展示更新提醒，点击即可一键下载并重启升级。打印导出组件与阿里云 OCR 组件在后续需要时按需安装。具体机制见[软件和组件更新](/update/)。
