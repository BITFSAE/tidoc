# Word 模板

Word 输出通过受限 DOCX 模板渲染。模板使用打印组件支持的变量、循环和过滤器。字段目录由共享轻量资源 [`context_fields.json`](../../tidoc_print/context_fields.json) 定义，核心注册表与组件读取同一来源，查看[生成参考](REFERENCE.md)。条目附加字段由所绑定的修订扩展目录。

模板校验会检查未知变量、作用域、循环深度和模板结构。渲染器使用严格未定义变量策略。变量拼写错误会使校验失败。模板不允许宏、嵌入对象、外部模板或外部图片关系。

使用真实 fixture 运行 `render`，再用实际办公软件检查代表性结果。CLI 可以验证内容、变量和生成文件结构，不能证明 Word、WPS 和 LibreOffice 的版式一致。早期 bundled LibreOffice 页图出现中文缺字；调整字体后，主线程完成样例的中文内容抽取及页图检查，段落、金额和表格正常。macOS 原生 Word、Windows 和代表性长表的验收仍未完成，见[验收记录](../TEAM_ADAPTER_PLAN.md#233-尚未完成的验收与现有产物)。

当前示例模板指定 Arial 和 Songti SC。Windows 缺少 Songti SC 时的字体回退、行高和分页仍需实机核对。

模板引用的图片必须放在包内并由模板验证器允许。不要使用外部 URL，也不要把个人信息固化进公共模板。

标签必须在同一 Word run 中输入。`{%p ... %}` 和 `{%tr ... %}` 分别放在结构控制段落或行中，不能在同一结构重复放置控制标签。校验按预处理后的完整 XML 部件解析循环，正文、页眉、页脚和脚注使用同一字段权限。`default` 只处理已声明字段的空值，不掩盖未知变量或严格未定义错误。
