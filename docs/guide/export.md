# 导出、打印与交接

整理好的[条目](/guide/concepts)可以根据需要导出：打包为 `.tidoc` 绑定包交给别人继续整理、导出总览 Excel 和附件整理包留档，或者生成报账方案规定的 Word 文档与材料 PDF 用于打印。

这几类操作都从选中条目开始：在主界面点击卡片勾选条目（按 `Cmd/Ctrl + A` 可以全选当前列表），再点击批量工具条里的「汇总」「导出」或「打印」。「汇总」会先列出条数、合计金额和抬头分布，可以用来快速核对。

## 交接给别人（`.tidoc` 绑定包）

### 导出绑定包

1. 勾选需要交接的条目。
2. 点击批量操作工具条中的「导出」。
3. 勾选「绑定包」（默认已选中），填写「导出名称」。
4. 点击「开始导出」。

生成完毕后，弹出的「导出完成」窗口会列出生成的文件；点击「打开」可直接预览，点击「文件夹」可在文件管理器中定位。导出文件保存在导出目录，也可以在「设置 → 数据位置」中点击「打开导出目录」找到。

![导出窗口](/images/export-dialog.png)

绑定包内包含条目、附件、报账人和文件完整性校验信息；阿里云 OCR 识别结果及比对状态也会一并保存。接收方需要使用支持报账方案的较新版本 Tidoc。

条目备注、附件备注（含修改记录）与标签是否导出，由「设置 → 报账方案 → 管理」中「绑定包」一组设置控制（「绑定包包含备注」「绑定包包含标签」，默认均开启）。选中的条目属于不同方案时，各条按自己方案的设置处理；方案固定的项不能修改。

::: warning 注意
绑定包中的发票、付款截图和报账人信息可以直接读取。完整性校验主要用于检查文件在传输中是否缺失或被改动，传输和保存时请使用团队认可的安全方式。
:::

### 导入绑定包

有三种方式打开导入预览：

- 点击主界面顶部工具栏的「导入包」，选取 `.tidoc` 文件。
- 把一个 `.tidoc` 文件拖入或在主界面按 `Cmd/Ctrl + V` 粘贴。
- 在文件管理器中双击 `.tidoc` 文件。

一次只处理一个绑定包，导入前需要已经创建报账人。Tidoc 只保留一个主窗口：软件已在运行时双击文件，文件会交给现有窗口；如果当时正在填写弹窗，导入预览会等弹窗关闭后再打开，不会打断当前输入。

「导入绑定包」预览顶部展示文件名、条目数、报账人及附件数量。导入前可以调整：

- **选择报账人**：勾选本次导入归属的报账人。如果本机已有同名报账人，默认匹配自己；可以直接修改报账人和审核人姓名；包内姓名对应本机多位同名报账人时，可以指定对应哪一位。
- **报账批次**：选择「不加入」「已有批次」或「新建批次」。有在办批次时默认归入「已有批次」，否则默认「新建批次」（自动预填绑定包名称）；选「不加入」时，导入前会再确认一次，避免条目无意中散落在「未进批次」。
- **统一标签（可选）**：为本次导入的所有条目统一追加一个标签。
- **条目清单**：取消勾选不需要导入的条目。
- **逐条批次调整**：点击「逐条调整」，可以为特定条目「单独设置」归属批次或「不加入批次」；点击「恢复统一设置」可回到上方的统一设置。
- **报账方案**：本机如果安装了多个方案，可以指定导入条目使用哪个方案。

确认无误后点击「确认导入」（按钮显示「导入 N 条」）。

![导入绑定包预览](/images/bindle-preview.png)

导入预览列表对每个条目与本机的关系进行标注：

| 标记 | 含义 |
| --- | --- |
| 新增 | 本机没有这张发票，按包内完整内容新建条目。 |
| 补充 | 本机已有这张发票，包内包含新附件或新字段，旁边列出将补充的内容。 |
| 已有 | 本机条目已包含包内全部材料和信息，不做改动。 |

遇到「补充」时，系统完整保留本机已录入的内容，把包内新增的材料（如查验单、付款截图）挂载到原条目，合并备注和普通标签，并补齐本机为空的基础信息、明细及云识别结果。「已报销 / 未报销」和「已支付 / 未支付」标签按包内状态更新，避免出现矛盾。标为「已有」的条目如果单独指定了目标批次，仍会按设置调整批次归属。

整次导入作为一个整体生效：如果导入中断或失败，系统会自动回滚，不会留下导入一半的数据。

::: tip 提示
若预览顶部提示「完整性校验未通过」，说明文件在传输中可能损坏或被改动。确认来源可靠后，勾选「我确认继续，导入后标记为严重问题」方可继续导入，条目入库后会显示为严重问题。
:::

## 导出 Excel 与附件整理包

在批量「导出」窗口中，除了绑定包，还可以勾选：

- **总览 Excel**：汇总提取发票代码、金额税额、报账人、材料状态及备注，方便负责人和财务核对。
- **规范命名附件包**（附件整理包）：系统自动解构条目附件，按「序号_发票号_销售方_金额」规则分文件夹整理所选条目的附件图片与 PDF，并压缩成 ZIP 包。

可以同时勾选多项，生成的文件名会在导出名称后分别加上「-总览」「-附件」等标识。这两类导出不需要安装打印导出组件。

## 报账打印（Word 审批单与材料拼接 PDF）

报账审批表单与材料拼接 PDF 通过批量工具条中的「打印」面板生成，具体模板由当前[报账方案](/guide/schemes)定义。

### 安装打印导出组件

Word 与材料 PDF 渲染依赖「打印导出组件」。若组件尚未就绪，「打印」窗口中的对应输出项将置灰并标注「需要安装或更新打印导出组件」：

1. 进入「设置 → 组件与更新 → 软件与组件」，点击「管理」。
2. 在「打印导出组件」行点击「安装组件」。
3. 安装完成后状态即时更新，返回「打印」窗口即可正常勾选。

详细机制见[软件和组件更新](/update/)。

### 生成打印文档

1. 选中待打印条目，点击批量操作工具条中的「打印」。
2. 在「生成内容」面板勾选本次所需文档。涉及收款信息的项标注「含收款信息」；折叠的「通用输出」包含不依赖方案的总览 Excel、附件整理包与通用材料 PDF。
3. 完善上下文信息：按需配置「文档日期」与「收款对象」；在「补充信息」中录入方案规定的批次属性（未建批次的条目可在此临时指定本次导出使用的批次信息）。
4. 临时微调：展开「本次调整」可临时修改本次导出的金额口径、条目排版顺序、材料编号规则与图片排版版式（此处仅影响本次生成，方案长期默认值在方案管理面板配置）。
5. 点击「生成」。

![打印导出窗口](/images/print-dialog.png)

点击「生成」后系统自动执行预检：

- **校验无误**：直接开始渲染生成。
- **存在阻断性问题**：窗口底部展示「无法生成，请先处理」并罗列具体条目与原因（如发票缺少必选 PDF、关键字段缺失）。需处理后再次点击「生成」。
- **仅存在一般提醒**：按钮切换为「仍然生成」，确认提醒后点击即可继续。
- **错误聚合收拢**：相同问题聚合展示；涉及多张发票时显示「涉及 N 条发票」，鼠标悬停可查看发票号码清单。
- **预估产物**：预检通过后，「预计生成」区清晰罗列将输出的文件名、文件类型与关联合同/收款对象。

变更输出勾选、调整日期或修改配置后，原有检查结果自动失效，再次点击「生成」将重新执行预检。必须至少选择一项有效输出方可触发生成。

仅录入 XML 而缺少发票 PDF 的条目，在需要输出票面留底的模板中将拦截并提示补充 PDF。无法直接转为 PDF 的非常规文件将在导出前拦截提醒，建议改用附件整理包留存原始文件。

生成期间，进度弹窗实时反馈当前处理阶段与任务计数。若需中止，点击「取消生成」，当前原子步骤完成后安全退出，不会产生残缺半成品文件。

生成完毕后，窗口自动切入「导出记录」，可直接点击调用系统程序打开文档。

### 收款对象管理与分摊

包含收款信息的文档（如团队报账说明、领款单）需指定合法收款对象。若方案未配置收款类输出，收款管理入口自动隐藏。

1. 在「打印」窗口点击「管理收款信息」，或前往「设置 → 个人收款信息」点击「填写」。
2. 点击「新建收款对象」，录入收款人姓名、人员编号（BITFSAE 方案显示为学号，须保留前导零）、手机号、账户类型、开户银行及银行卡号。收款信息仅保存在本机，绝不写入交接绑定包。
3. 返回「打印」窗口，在「收款对象」下拉框中选定本次应用的收款人；留空则默认继承批次或方案默认对象。

收款分摊逻辑由方案底层配置决定：

- **统一收款**：整批报账统一使用同一收款账户。
- **分别收款**：方案配置为分别收款时，必须在「个人收款信息」中为每位关联报账人分别指定独立收款账户，不支持回退至全局默认对象。「收款对象」栏将明确标注「按报账人分别收款」。

预检面板将呈现选定对象的脱敏卡号（如尾号 4 位）。若信息残缺将明确指出「需补充：开户行、账号」等缺失字段，系统不作模糊竞猜。

### 导出历史与溯源

每次打印导出均会在本机数据仓库留存完整的历史快照。生成完毕后自动弹出，后续亦可在「设置 → 导出记录」中调阅。

- 点击「打开」直接调用默认程序打开文件，点击「打开文件夹」定位本地物理目录。
- 支持「按原数据重新生成」：系统严格调取当时保存的历史数据快照重新渲染输出，完全不受后续条目修改的影响（若原始关联附件物理文件已被移除则会提示）。
- 生成期间触发的各项非阻断性提醒在记录详情中永久归档，便于对照发票号回溯审计。
- 事务安全：中途取消或执行失败的导出任务不产生残留记录。

若系统报告导出记录写入失败，需优先排查磁盘剩余可用空间与本地目录写权限。
