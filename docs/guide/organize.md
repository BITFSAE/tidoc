# 筛选、标签与批次

面对较多发票时，可通过多维检索定位条目、利用标签划分业务类目，并通过报账批次组织阶段性提交任务。

## 搜索与多维筛选

点击搜索框或按快捷键 `/` 激活搜索。支持检索发票号码、销方名称、金额数值、条目备注及物资名称。

工具条支持多维属性交叉过滤：

- **基础下拉筛选**：按「抬头」「报账人」「标签」过滤条目（默认呈现「全部」）。
- **列表排序**：支持按更新时间、创建时间、发票开票日期、金额或销售方升降序排列。
- **高级筛选**：展开「高级」面板可设置发票日期区间、金额数值范围，以及按「校验状态」（通过、识别提醒、严重问题）、「条目备注」（有备注、无备注）和「付款截图数量」精确过滤。点击「清空全部筛选」重置为默认。

![状态视图和筛选工具条](/images/status-views.png)

状态视图（「待补材料」「识别提醒」「齐备」等，详见[核对识别结果](/guide/check)）、批次分类与筛选条件支持叠加生效。例如：选定特定在办批次，切换至「待补材料」状态视图，再筛选指定报账人，即可精准聚焦该报账人在本批次中尚缺的支撑凭证。

::: tip 提示
在「标签」下拉框或「高级」面板调整筛选条件时，顶部状态视图将自动重置为「全部」。若需结合使用，建议先配置标签与高级条件，再切换对应状态视图。
:::

## 条目多选交互

- **单选/反选**：点击卡片切换选中状态。选中状态下卡片呈现高亮且左边缘显示标识竖线。
- **范围连选**：按住 `Shift` 并点击另一卡片，连续选定两张卡片之间的全部条目。
- **键盘导航**：方向键在卡片间聚焦移动，按空格键切换选中/取消，按 `Shift + 空格` 连续扩选，按 `Enter` 直接打开详情。
- **全选**：按 `Cmd/Ctrl + A` 或点击工具条「全选」按钮，选定当前列表展示的全部条目。
- **清除选区**：按 `Esc` 清空当前选择。

切换状态视图、筛选维度或批次标签页时，已选条目将自动清空。

## 批量操作工具条

勾选一张或多张条目后，列表上方将唤起批量操作工具条，显示「已选 N」及批处理动作：

![选中多张卡片后的批量工具条](/images/batch-toolbar.png)

- 「批次」：将所选条目分配或移至目标批次。
- 「标签」：批量追加或移除标签。
- 「报账人」：批量变更所属报账人。
- 「重新识别」：批量刷新发票元数据或付款截图提取结果，详见[核对识别结果](/guide/check)。
- 「云识别」：调用阿里云 OCR 接口（需安装 OCR 识别组件），详见[阿里云 OCR](/guide/aliyun-ocr)。
- 「汇总」「导出」「打印」：核对汇总要素或批量输出交付物，详见[导出、打印与交接](/guide/export)。
- 「删除」：永久删除所选条目及其关联的所有附件文件（不可撤销）。

右键点击单张卡片亦可在上下文菜单中执行对应的单条处理。

## 标签管理

[标签](/guide/concepts)用于自定义分类管理（如「电控」「底盘物资」「研发测试」）：

1. 选中条目，点击工具条「标签」按钮或按快捷键 `T`。
2. 在「标签」窗口中选择「添加」或「移除」模式。
3. 输入标签名称后回车，或直接勾选已有标签库中的条目。

若需统一维护标签库，点击窗口内的「管理标签」：
- 点击标签名称可就地重命名；重命名为已有标签名时系统将自动合并。
- 点击标签右侧删除图标，将从所有关联条目中移除该标签。删除标签仅解除标记关系，不影响条目本身与附件文件。

## 报账批次管理

[报账批次](/guide/concepts)代表一次报销申报的完整集合。批次栏位于工具条次级区域，划分为「在办」与「已归档」两个标签页，并常驻「未进批次」入口；每个批次清晰显示条目总数与缺材料数。

### 建立批次并纳入条目

1. 勾选准备集中报账的条目。
2. 点击批量工具条中的「批次」按钮，在弹窗中选择「新建批次」。
3. 填写「批次名称」，可按需录入「批次备注」，点击「创建」。

批次工具栏右侧的「新建批次」按钮亦可独立创建批次；若此时已有选中的条目，系统将联动将其一并纳入。导入发票时亦可同步分配或新建批次，详见[导入发票](/guide/import)。

### 调整条目批次归属

1. 选中目标条目，点击批量工具条中的「批次」。
2. 在批次分配弹窗中选定目标批次，或选择「未进批次」。
3. 点击「确认移动」（若所选条目此前均未分配批次，按钮呈现为「确认加入」）。

单个条目仅从属于一个批次，移入新批次后自动脱离原批次。点击卡片上的批次徽标或右键卡片选择「批次」可对单条条目调整归属；在特定批次视图下，右键卡片选择「移出当前批次」，条目将重置为「未进批次」。

### 查看与筛选批次

点击批次栏中的批次名，工作台仅展示该批次包含的条目；再次点击当前选中批次，恢复展示全部条目。批次名称右侧实时展现统计指标（如「缺 N」或「齐」）。

### 维护批次备注与催办信息

点击批次右侧「⋯」展开扩展操作：

- **编辑批次**：修改批次名称与备注。窗口内的「批次报账信息」用于录入方案定制要素及选定本批次的收款对象，详见[导出、打印与交接](/guide/export)。
- **批次备注**：录入经费卡号、申报要点或交接提醒。
- **批次催办备注**：在批次视图下右键点击特定卡片，选择「批次催办备注」，可为该发票设置催办备忘并直观展示于卡片表面。

![批次编辑窗口](/images/batch-edit.png)

### 归档与复原

报销办结后可归档批次，保持工作台整洁：

1. 点击目标批次右侧「⋯」更多操作，选择「归档批次」。
2. 归档确认弹窗将展示本批条目数、金额合计及仍缺材料的条目数；核实无误后点击「确认归档」。

归档后，批次及关联条目移出「在办」列表，可在批次栏「已归档」标签页中检索查阅。如需重新编辑，点击「⋯」选择「恢复到在办」。

### 删除批次

点击目标批次右侧「⋯」，选择「删除批次」。

默认仅删除批次分组定义，条目本身与挂载材料完整保留，自动退回「未进批次」。

::: warning 注意
若在弹窗中勾选「同时永久删除条目」，确认按钮将切换为「永久删除批次和条目」，该批次下的条目及其所有附件文件将被永久抹除，不可撤销。
:::
