# 常见问题

按问题所在的环节分组，找到现象后按「原因」和「处理」操作。

## 导入与识别

### 发票是扫描件或照片，识别不到字段怎么办

**原因**：本地识别读取的是发票 XML 或 PDF 里的文字。扫描件和照片转成的 PDF 只有图像，没有文字，读不到发票号码、金额等字段。

**处理**：

- 在[条目](/guide/concepts)详情里手动填写缺失的字段。
- 或者使用阿里云 OCR 云识别，由云端读取图像里的内容，见[阿里云 OCR](/guide/aliyun-ocr)。云识别有每月免费额度，超出后按调用量计费。
- 有电子发票 XML 时，一并导入可以得到完整的结构化数据，见[导入发票](/guide/import)。

### XML 没有进入批量导入预览怎么办

**原因**：批量导入会把能识别发票号码的独立 XML 放进导入组。没有进入预览，通常是文件不是受支持的发票 XML、文件已损坏，或者同一张发票这次已经导入过。

**处理**：先用「新建」单独导入这个 XML，查看具体的错误提示。需要打印票面的输出还要补充发票 PDF。

### 软件升级后，如何重新处理旧发票

**原因**：识别规则随版本改进，旧条目保留的是当时的识别结果。

**处理**：在「识别提醒」或其他列表里选中条目，点击批量工具条中的「重新识别」。软件在本机按当前规则重新读取需要更新的发票，内容相同且已按当前规则处理过的会跳过。付款截图要重新识别时，选中条目点「云识别」，勾选「付款截图 · AI」。

### 云识别提示出错怎么办

按提示对照[阿里云 OCR](/guide/aliyun-ocr)页面末尾的「常见错误」处理，多数问题出在 AccessKey 填写错误、权限或服务未开通。

## 材料

### 付款截图没有自动绑定怎么办

**原因**：截图没有识别到金额、多个条目的金额相同，或截图中有多个付款数字。「添加截图时自动识别」默认关闭，关闭时需要手动指定条目。

**处理**：点击对应卡片上的「付款」添加截图，或在弹出的「绑定材料」窗口里手动选择条目。

### 查验单没有自动归档怎么办

**原因**：自动保存失败，或系统打印保存的 PDF 不在监测的文件夹里、读不到发票号码。

**处理**：依次检查：

1. 官网是否已经显示当前发票的详情，且「在线查验」窗口还开着。
2. 提示自动保存失败时，点击官网「打印」另存为 PDF。
3. 用系统打印保存时，PDF 是否在「下载」「桌面」「文档」或「设置」里的「额外归档目录」。
4. PDF 里是否有可读取的发票号码，且与当前条目一致。

仍然没有归档时，在卡片或详情里手动上传查验单。

## 导出与打印

### 点击「打印」后 Word 和材料 PDF 不能勾选怎么办

**原因**：Word 和材料 PDF 由打印导出组件生成，该组件还没有安装，对应输出显示「需要安装或更新打印导出组件」。

**处理**：打开「设置 → 组件与更新 → 软件与组件 → 管理」，安装打印导出组件，见[软件和组件更新](/update/)。

### Word 中缺少姓名或银行卡信息怎么办

**原因**：文档里的收款段落来自收款对象，没有选择收款对象，或者对象的姓名、开户行、账号没有填全。

**处理**：在「打印」窗口点击「管理收款信息」，补全收款对象的信息，再在「收款对象」里选中。方案设为分别收款时，每位报账人都要指定收款对象。没有收款段落的文档不需要银行信息。详见[导出、打印与交接](/guide/export)。

### 导入绑定包时出现重复发票怎么办

**原因**：绑定包里的发票本机已经有了。

**处理**：预览里的标记说明了会发生什么。「已有·待补充」会把本机缺少的材料和信息合并到原条目，不覆盖本机已有的内容；「已有·无变化」表示本机条目已包含包内内容，无需补充。已有条目默认留在原来的批次，要移动时见[导入绑定包](/guide/export#导入绑定包)。

### 双击 `.tidoc` 文件后图标没有刷新怎么办

**原因**：系统尚未更新文件关联的图标缓存。

**处理**：先确认已经安装当前版本的 Tidoc。Windows 可以注销后重新登录，或重启资源管理器；macOS 可以重新打开 Finder。

## 批次

### 删除批次后，条目还在怎么办

批次用于组织条目。「删除批次」默认保留条目，条目回到「未进批次」。需要一起清理时，在确认窗口勾选「同时永久删除条目」，条目及其全部材料会被删除，确认后无法恢复。

## 数据与更新

### 数据保存在哪里，会上传吗

条目、材料和设置都保存在本机的数据文件夹，位置在「设置 → 数据位置」里可以看到。Tidoc 不会自动上传你的发票和材料。

只有少数操作会联网，例如在线查验、用取票二维码取票、点击「云识别」和检查更新，完整列表见[设置与数据](/guide/settings#本机数据与联网)。

### 换电脑时，如何迁移数据

整体迁移：

1. 在旧电脑退出 Tidoc，按[设置与数据](/guide/settings)里的备份步骤复制整个数据文件夹。
2. 在新电脑安装 Tidoc，打开一次后退出，在「设置 → 数据位置」确认数据文件夹的路径。
3. 按同一页的恢复步骤，用备份替换新电脑的数据文件夹，再启动 Tidoc 检查报账人、条目和材料。
4. 到「设置 → 开发者选项 → 发票阿里云 OCR」确认密钥是否已配置；打印导出组件和 OCR 识别组件显示「未安装」或「需要修复」时，在「软件与组件」里重新安装。

只迁移一部分条目：在旧电脑选中条目导出 `.tidoc` 绑定包，在新电脑导入，见[导出、打印与交接](/guide/export)。

### 组件显示「需要修复」怎么办

组件文件缺失或损坏时会显示「需要修复」。在「软件与组件」窗口点击「修复组件」重新安装，见[软件和组件更新](/update/)。

## 反馈与交流

### 遇到识别有误的发票怎么办？如何提供样本？

发票版式很多，如果遇到本地识别不准、金额核算有偏差或明细漏项的发票：

1. **邮箱发送样本**：把脱敏后的发票文件（PDF 或 XML，隐去个人信息）发送到邮箱 `info@bitfsae.com`，我们据此补充测试和适配。
2. **GitHub 提交反馈**：在 [GitHub Issues](https://github.com/BITFSAE/tidoc/issues) 提出反馈，附上异常现象描述。

### 有功能建议或想参与开发贡献？

欢迎在 GitHub 提交 Issue 或 Pull Request 进行交流。面向开发者的说明请查阅[开发相关](/dev/)。
