# 导入发票

Tidoc 支持通过批量导入、拖拽放置、剪贴板粘贴与手动新建四种方式录入发票。每张发票生成一个独立[条目](/guide/concepts)，导入时可同步分配归属报账人与[报账批次](/guide/concepts)。

## 批量导入多张发票

1. 点击主界面右上角「导入发票」。
2. 在「批量导入」窗口中点击「选择文件夹」或「多选发票文件」。选择文件夹时，系统将递归扫描目录内各级子文件夹中的发票 PDF 与 XML 文件。
3. 在「确认导入」窗口中核对解析出的发票分组；若有不需要导入的文件，取消勾选对应分组的「导入」。
4. 指定「报账人」与「报账批次」。若列表中无对应报账人，点击「新建报账人」；在批次下拉框中选择「＋ 新建批次…」并输入名称，可直接创建新批次。
5. 点击「创建选中条目」。

![确认导入窗口，列出识别出的发票分组](/images/import-preview.png)

导入预检分组规则如下：

- 每个发票 PDF 对应建立一个条目。若同批包含对应发票的 XML 文件，系统自动完成配对（优先比对发票号码，次优先比对文件名相似度），并优先提取 XML 结构化数据。
- 具备有效发票号但缺少 PDF 的 XML 将独立成组，支持先行导入（后续补充 PDF 票面）。
- 无法解析出有效发票号的 XML 归入「未匹配 XML」，需检查文件有效性后重试。
- 付款截图、查验单、重复发票以及包含多页不同发票的合并 PDF 归入「未参与批量」，不会直接建条。多发票合并的 PDF 须先拆分为单发票文件。
- 若某分组建条异常，该组将高亮标红并提示错误原因，其余正常分组不受影响。

付款截图与查验单通常在条目建立后追加，详见[补齐材料](/guide/materials)；亦支持在导入阶段协同载入。

## 拖拽导入

拖拽文件进入 Tidoc 窗口时，系统根据释放落点与文件类型执行不同动作：

- **拖至主工作台空白区域**：作为新批次材料读取。发票 PDF 与 XML 打开「确认导入」预览窗口；[绑定包](/guide/concepts)（`.tidoc` 文件）直接呼出导入包预览；付款截图、实物照片与查验单则尝试自动关联现有条目。
- **拖至特定条目卡片**：将付款截图、实物照片或查验单直接追加至该条目。若拖入发票文件，其发票号码须与当前卡片一致，否则提示「这张发票不属于当前条目」。
- **拖至条目详情中的「报账材料」区域**：追加至当前条目对应的材料分类组。

若混合拖入发票与关联材料，系统将先识别文件类型再执行分配：查验单根据发票号码自动关联，付款截图在开启金额识别时尝试按金额匹配。无法自动确定归属的文件将弹出「绑定材料」窗口，由人工指定关联条目。

拖拽交互反馈：文件移入主界面时，空白区域展示虚线框并提示可导入类型；悬停至特定卡片时，目标卡片单独高亮响应。条目详情打开状态下，各材料分组区域支持独立拖拽高亮。

## 粘贴导入

在访达（Finder）或文件资源管理器中复制文件后，直接在 Tidoc 界面按 `Cmd/Ctrl + V`：

- **在主工作台粘贴发票**：打开「确认导入」窗口，可批量指定报账人与目标批次。
- **在条目详情中粘贴材料**：付款截图、实物照片或查验单直接录入当前条目，并实时反馈解析状态。
- **在主工作台粘贴支撑材料**：处理逻辑与拖放至空白区域一致。

## 手动新建条目

适用于单张发票录入或逐项手动核对场景：

1. 点击主界面右上角「新建」按钮，或按快捷键 `N`。
2. 在「新建报账条目」窗口中选定购买方抬头与归属报账人。
3. 上传「发票 PDF」与「发票 XML」（建议二者均提供，以保障数据完整与票面齐备）；「付款截图」「实物图」「查验单 PDF」可在此选填，亦可建条后补充。
4. 选取发票文件后，窗口右侧实时呈现解析预览；核实发票号码、开票日期、销方名称、购买方抬头、价税合计及明细行数。
5. 点击「保存」完成录入。

## 先导 XML 后补 PDF

数电发票 XML 包含完整的发票号码、金额、税额与物品明细数据，PDF 则提供归档与打印所需的票面底本。两者允许分步录入：

1. 先行通过「导入发票」或「新建」载入 XML。导入预览中该组会标注「先导入 XML；打印票面前补充发票 PDF」。
2. 获取 PDF 票面后，点击卡片上的「发票」按钮选取文件，或直接将 PDF 拖拽至目标卡片完成补充。

生成需打印票面的导出文档（如材料拼接 PDF）前必须具备发票 PDF。若生成时缺失 PDF，系统将在导出预检环节明确拦截提示，补齐后即可继续。详见[导出、打印与交接](/guide/export)。

## 发票查重机制

Tidoc 在全量条目（包含已归档批次）范围内执行发票查重：优先比对发票号码，次优先比对文件哈希。

若检测到发票已存在，该组不予新建，并在列表标注「未创建」及原条目信息（发票号码、销售方、所属报账人）。手动「新建」时亦会弹窗提示冲突。如需变更发票所属人，应直接修改已有条目的报账人，无需重复导入。单次批量导入中若出现相同发票号的重复文件，后续文件将归入「未参与批量」。

## 常见问题

### 从微信拖入时提示「无法读取」怎么办

**原因**：微信等即时通讯工具的临时接收目录具有沙盒或系统权限限制，外部程序无法直接读取。  
**处理**：在聊天软件中将文件「另存为」至桌面或「下载」目录后，再拖入 Tidoc。

### XML 未出现在导入预览窗口怎么办

依次排查以下情况：

1. 确认该 XML 是否为税务局规范格式的电子发票 XML，文件是否完整无损坏。
2. 确认同批导入中是否已包含相同发票号码的文件。
3. 尝试在「新建」窗口中单独上传该 XML，查看系统返回的具体校验错误信息。

需打印票面的导出件仍需补充对应 PDF。
