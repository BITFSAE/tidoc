# 报账方案

报账方案（简称方案）定义一套报账规则：单位抬头与税号、要求提交哪些材料、需要填写哪些信息，以及生成哪些文档。不同团队使用不同方案，本页说明如何选择、调整和安装方案。

## 首次选择

首次打开 Tidoc 时，会显示「选择报账方案」窗口：

- 「通用报账」：不预填抬头，只要求发票。输出报账说明、材料 PDF、总览表和附件整理包。
- 「BITFSAE 车队报账」：包含北京理工大学和北京理工大学教育基金会两个抬头，审核人必填，要求付款截图。输出「报账说明」「验收单」和「按条目材料拼接 PDF」等。
- 「导入报账方案」：安装团队管理员提供的 `.tidoc-preset` 文件，见[安装团队方案文件](#安装团队方案文件)。

![首次选择报账方案](/images/first-run-scheme.png)

选好方案后继续创建报账人。之后想换方案，在「设置 → 报账方案 → 管理」的「当前方案」里选中另一个方案，点击「设为默认」。默认方案只影响之后新建的[条目](/guide/concepts)，已有条目保留创建时的规则。

## 调整方案

打开「设置 → 报账方案 → 管理」。窗口上方是方案的说明、版本、作者以及抬头、材料、输出的数量，下方按分组列出可以调整的内容。

![报账方案管理窗口](/images/scheme-settings.png)

修改后点击底部的「保存更改」（有改动时显示为「保存 N 项更改」）。有未保存的更改时关闭窗口，会先询问是否放弃。被改过的项显示「已自定义」，点「恢复默认」回到方案自带的值；底部的「全部恢复默认」一次恢复所有项。显示「方案固定」的项由方案规定，不能修改。

### 抬头与税号

「抬头与税号」里可以添加、移除抬头并填写税号。发票识别和校验按这些抬头和税号进行：抬头不在列表里、购买方税号缺失或不匹配时，条目会出现识别提醒。没有配置任何抬头时，只提示明细与金额问题，不按抬头校验。

新添加的抬头保存后，才能在「条目录入」里选为默认抬头。

### 材料要求

「材料要求」决定条目要补齐哪些材料才算「齐备」：

- 发票始终必需，PDF 或 XML 均可。
- 「付款截图」「实物图」「查验单」「实付金额」可以分别设为「必需」或「可选」。
- 方案自己规定的其他材料（例如合同、审批单）按方案显示名称和份数要求，只读。

### 其他设置

| 分组 | 可以调整的内容 |
| --- | --- |
| 条目录入 | 默认抬头、实付初值取发票总额、建议标签 |
| 报账人与收款 | 初始报账人视图、审核人必填、审核人显示方式、人员编号名称（如学号、工号） |
| 打印与导出 | 默认输出、金额口径、收款方式、条目排序、材料排序、材料编号、图片布局 |
| 识别与查验 | 付款截图金额识别（实验性）、显示云识别入口、显示查验入口 |
| 绑定包 | 绑定包是否包含备注、是否包含标签 |

方案没有对应功能时，相关设置不会显示。例如没有需要收款的输出，就没有收款方式和人员编号名称。

「付款截图金额识别」默认是「手动填写」，需要时可以改为「本地识别」，识别结果仅供参考。

窗口顶部还有几个方案级操作：

- 「收款信息」：填写文档里需要的收款对象，见[导出、打印与交接](/guide/export)。方案没有需要收款的输出时不显示。
- 「复制方案」：基于当前方案建一个副本。副本沿用设置，收款信息和个人填写值不会复制。
- 「历史版本」：查看每次保存留下的版本，可以「回到此版本」。
- 「停用」：停用当前不是默认的方案。被停用的方案不再出现在新建条目的选择中，已使用它的条目不受影响，可以在窗口底部「已停用的方案」里「重新启用」。

## 修改方案以后，已有条目怎么处理

每次保存方案设置都会生成一个新版本。新建条目使用当前版本，已有条目仍按创建时的规则判断是否齐备、生成文档。保存后会提示「已保存。新建条目使用新设置，已有条目沿用原规则。」

需要让某个已有条目改用新规则，或改用另一个方案：

1. 打开该条目的详情，展开底部的「报账方案」。
2. 点击「更改方案」。
3. 选择「目标方案」，点击「预览变化」，查看每个条目的状态变化，例如「齐备 → 待补材料」。
4. 确认无误后点击「应用到这些条目」。

发票原始信息和附件在这个过程中保持不变。

在「历史版本」里选择「回到此版本」后，新建条目使用所选版本，已有条目同样不受影响，当前版本仍保留在历史里，可以再切换回来。

## 安装团队方案文件

团队管理员可以提供 `.tidoc-preset` 文件，里面是团队的抬头、材料要求、输出模板等规则，不含个人姓名、收款账号、条目或导出历史。

1. 把文件单独拖入 Tidoc 窗口（一次只拖一个文件），或在方案管理窗口点击「导入方案…」选择文件。
2. 在「导入报账方案」窗口检查方案名称、版本、作者和检查结果。
3. 在「安装方式」里选择「安装为新方案」或「另存本地副本」。本机已有同一方案时，还可以选择「更新已有方案」，遇到冲突时逐项选择处理方式。
4. 点击「安装方案」。

安装后的方案保存在本机。想用它新建条目，在方案管理窗口把它「设为默认」。如果方案包含 Word 或 PDF 输出，还需要安装打印导出组件，并在本机补充收款信息和团队要求的字段。

团队管理员想把本机的方案分享给队友，可以点击「导出方案」，生成的 `.tidoc-preset` 文件不含收款对象、账号、个人填写值和历史记录。
