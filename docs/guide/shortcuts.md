# 快捷操作

用键盘和鼠标处理[条目](/guide/concepts)可以减少来回点击。本页按用途列出常用操作，`Cmd` 用于 macOS，`Ctrl` 用于 Windows。

::: tip 提示
`/`、`N`、`T` 和 `Cmd/Ctrl + A` 在主界面的列表里使用。光标在输入框里，或者有弹窗打开时，这些按键不触发列表操作。
:::

## 选择

| 操作 | 效果 |
| --- | --- |
| 点击卡片 | 选中或取消选中该条目。选中的卡片整体变蓝，左缘多一条蓝色短竖线 |
| `Shift` + 点击 | 从上次选中的卡片连续选到这一张 |
| 方向键 | 在卡片之间移动 |
| `Shift` + 方向键 | 移动的同时连续选中 |
| `Home` / `End` | 跳到列表的第一张 / 最后一张 |
| `PageUp` / `PageDown` | 向上 / 向下跳 5 张 |
| 空格 | 选中或取消选中当前卡片，`Shift` + 空格连续选择 |
| `Cmd/Ctrl + A` | 选择当前列表中的全部条目 |
| `Esc` | 有弹窗时关闭弹窗；否则清除当前选择。在输入框里退出输入 |

## 打开与搜索

| 操作 | 效果 |
| --- | --- |
| `Enter` | 打开当前卡片的详情 |
| `/` | 光标跳到搜索框，可搜索发票号、销售方、金额、备注和物资名称 |
| `N` | 新建条目 |
| 右键卡片 | 打开条目菜单 |
| 菜单键，或 `Shift + F10` | 在键盘焦点所在的卡片上打开条目菜单 |

条目菜单包含「打开详情」「填写实付金额」「添加付款截图」「在线查验」「上传已有查验单」「添加发票 PDF」「编辑条目备注」「打标签」「批次」和「删除条目」。安装 OCR 识别组件后多出「阿里云识别」；在某个批次里查看时，「批次」换成「移出当前批次」，并多出「批次催办备注」。

## 标签与批量

| 操作 | 效果 |
| --- | --- |
| `T` | 给已选条目添加或移除标签，需要先选中条目 |
| 右键批量工具条里的「标签」 | 为已选条目批量填写方案要求的报账信息（例如 BITFSAE 的采购用途、存放地点） |

选中条目后，批量工具条里的「批次」「标签」「报账人」「重新识别」「云识别」（安装 OCR 识别组件后显示）「汇总」「导出」「打印」「删除」作用于所有已选条目。

## 文件

| 操作 | 效果 |
| --- | --- |
| 把文件拖到卡片上 | 添加到该条目的材料，拖动时只有这张卡片高亮 |
| 把文件拖到主界面空白处 | 导入发票 PDF、XML 或 `.tidoc` 绑定包，其他材料会尝试匹配现有条目 |
| `Cmd/Ctrl + V` | 粘贴在文件管理器中复制的文件。在条目详情里粘贴，材料直接归入该条目；在主界面粘贴，与拖到空白处相同 |
| 点击卡片上的「发票」「付款」「查验」「实物」 | 为该条目继续添加对应材料 |
| 右键卡片上的「发票」「付款」「查验」「实物」 | 直接打开该条目已有的对应文件 |
| 打印导出窗口刚打开时按 `Enter` | 按当前选择开始检查并生成 |
