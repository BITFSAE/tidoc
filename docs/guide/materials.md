# 补齐材料

发票录入后，需为对应[条目](/guide/concepts)补充关联的付款截图、实物照片与查验单，并确认实付金额。本页说明材料录入入口、查验归档流程与材料齐备规则配置。

## 条目卡片快捷操作

卡片右侧提供常用支撑材料的快捷操作入口：

- 「发票」：补录发票 PDF（例如先导 XML 的条目）。
- 「实付」：录入或订正实际支付金额。
- 「付款」：添加付款截图，支持多选批量上传；存在多张时显示数量徽标。
- 「查验」：调起税务查验流程，流程见下文。
- 「实物」：添加单张或多张采购实物拍摄图（方案要求实物图或条目已有实物图时显示该按钮）。
- 「详情」：进入条目详情全量视图（无「实物」按钮时显示为「打开详情」）。

已挂载材料的按钮呈现完成状态；再次点击可追加同类材料，右键点击按钮可直接调用系统默认程序打开文件。

![卡片上的材料按钮和状态徽标](/images/card-actions.png)

右键点击卡片弹出的上下文菜单同样提供上述操作，详见[快捷操作](/guide/shortcuts)。将文件直接拖拽至目标卡片亦可完成材料添加，详见[导入发票](/guide/import)。

## 条目详情全量管理

若需系统化复核或录入多项支撑材料，点击卡片「详情」（或选中卡片按 `Enter`）进入条目详情：

1. **报账材料分组**：查看各材料类别状态，分组标题清晰标明「必需」或「可选」属性及已挂载附件数量。
2. **添加与管理**：点击各组右侧「＋ 添加」（查验单为「＋ 上传」与「在线查验」）选择文件；单条附件支持「打开」「位置」（在文件管理器中定位）、「替换」「删除」，并可在「附件备注」中录入说明。
3. **关键业务字段**：在「需要手动确认」区域维护「实付金额」「实际物资名称」与「条目备注」，修改后实时自动保存。
4. **快捷注入**：直接将附件拖放至「报账材料」区域或直接在详情中按 `Cmd/Ctrl + V` 粘贴，文件即归入当前条目。

::: tip 提示
若发票开具品名与实际采购物品不一致（如开具为广义类目），可在「实际物资名称」中填写真实物品名称，卡片工作台将优先展示该自定义名称。
:::

## 付款截图与实付金额

实付金额取值逻辑：

- **默认取值**：根据方案「实付初值取发票总额」配置（默认开启），条目创建时实付金额初始设为发票价税合计；若发票未能解析出总额，该项留空待填。
- **人工调整**：若存在分笔支付、折扣让利或垫付差额，点击卡片「实付」按钮或在详情中修改。实付金额与发票金额不一致的条目，卡片将标注「已修改」徽标，并归入「已修改」状态视图。

付款截图金额识别（实验性）：

该功能默认关闭，添加截图后需人工核验实付金额。如需开启，进入「设置 → 报账方案 → 管理」，将「付款截图金额识别（实验性）」设为「本地识别」。该功能调用系统原生文字识别框架提取数字，结果仅供参考。开启后的处理流程：

- 若单张截图金额与发票总额匹配，自动填入实付金额。
- 若添加多张截图或识别金额与发票不符，系统弹出「实付金额」确认弹窗，展示识别到的各笔流水及汇总金额，可选择「按截图填入」「手动填写」或「保留当前值」。

## 在线查验并自动归档

在线查验将调起国家税务总局全国增值税发票查验平台，此过程需连接互联网。

1. 点击卡片上的「查验」，打开「在线查验」弹窗。
2. 核对系统提取的「发票号码」「开票日期」与「价税合计」（开票日期格式为 `YYYYMMDD`）。
3. 点击「打开查验官网」，系统将启动外部浏览器打开税务查验平台并自动预填查验要素。
4. 在官网页面完成图片验证码校验，点击「查验」。
5. 查验结果展现后，点击官网页面内的「打印」，在系统打印对话框中将排版设为横向，另存为 PDF 文件。
6. 将 PDF 文件保存至系统「下载」「桌面」「文稿/文档」目录，或预设的额外归档目录。
7. 稍候 1–2 秒，Tidoc 弹窗将提示「查验单已保存」，文件自动挂载归入当前条目。

::: tip 提示
全国发票查验平台首次查验生成的查验凭单包含完整的首查标记与认证记录，建议查验后立即导出归档。
:::

若已持有查验单 PDF，可在「在线查验」弹窗点击「上传已有 PDF」，或在卡片右键菜单选择「上传已有查验单」，亦可直接将文件拖拽至卡片。

若常用下载目录非上述系统默认目录，可在「设置 → 查验单」中指定额外监测目录，详见[设置与数据](/guide/settings)。

## 设置材料齐备规则

条目的[材料齐备](/guide/concepts)状态由方案的「材料要求」规则判定。可在设置中自定义必需与选填项：

1. 点击主界面右上角「设置」图标，在「报账方案」行点击「管理」。
2. 在「材料要求」分组中，分别将「付款截图」「实物图」「查验单」「实付金额」指定为「必需」或「可选」（发票本身固定为必需项，提供 PDF 或 XML 均可）。
3. 点击「保存更改」。

方案内置的专有材料（如合同协议、资产验收单等）在管理面板中为只读属性，具体格式与份数要求可在条目详情的材料分组中查看。

保存配置后，新建条目将立即应用新规则；已有历史条目默认保留创建时的规则判定。若需为旧条目更新规则，见[报账方案](/guide/schemes)。

## 常见问题

### 付款截图未自动绑定到条目怎么办

开启金额识别后，拖拽或粘贴的付款截图根据解析金额与条目发票金额进行匹配。匹配未命中常见于：截图金额未成功识别、多个条目存在完全相同的金额、截图内存在多个混淆数字。此时可直接点击目标卡片「付款」按钮添加，或在弹出的「绑定材料」窗口中手动选择归属条目。

### 查验单未自动归档怎么办

依次排查以下环节：

1. 查验单是否通过税务局查验官网内置的「打印」按钮另存为标准 PDF。
2. PDF 文件是否存放在「下载」「桌面」「文稿/文档」或设置中指定的额外归档目录。
3. 查验单 PDF 文本图层中是否包含清晰有效的发票号码。
4. 当前条目的「在线查验」弹窗是否保持开启状态。

若仍未自动捕获，可在卡片快捷操作或条目详情中手动上传查验单 PDF。
