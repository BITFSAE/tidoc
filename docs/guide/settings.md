# 设置与数据

点击主界面右上角齿轮图标进入「设置」面板。本页说明报账人归属、界面偏好、发票查验单监测、数据存储路径、整库备份迁移以及本地隐私与联网边界。

![设置](/images/settings.png)

「报账方案」「个人收款信息」「导出记录」位于设置顶部导航区，详见[报账方案](/guide/schemes)与[导出、打印与交接](/guide/export)；「阿里云 OCR」详见[阿里云 OCR](/guide/aliyun-ocr)；「组件与更新」详见[软件和组件更新](/update/)。设置底部的「使用提示」可用于重置新手引导气泡。

## 报账人与代填模式

报账人用于标记发票及报销费用的实际所有权，详见[基本概念](/guide/concepts)。

1. 在设置面板「报账人」行点击「管理」，打开「报账人管理」弹窗。
2. 在「新增报账人」区域录入姓名，并根据方案要求指定关联审核人，点击「添加报账人」。
3. 已有报账人支持就地「编辑」「设为默认」或「删除」。

姓名为必填字段；审核人是否必填或作为高级选项呈现由[报账方案](/guide/schemes)定义。

**代填模式**适用于单台计算机集中代理多人整理申报的场景。开启后，在手动新建、批量文件夹导入及导入绑定包时，系统均允许指定具体发票归属人。当录入第二位报账人时系统自动激活代填模式，亦可在设置面板中手动启闭。

## 界面偏好

在「设置 → 偏好」中可定制个性化工作台行为：

- **启动默认抬头**：指定应用启动后默认聚焦的购买方抬头选项卡。
- **默认列表密度**：切换工作台卡片排版密度（「标准」或「精简」）。
- **外观主题**：支持「跟随系统」「浅色」或「深色」（主界面顶栏的日月图标亦可一键切换）。
- **卡片显示创建时间**：在卡片表面直观展示精确至分钟的条目创建时间戳（默认关闭）。

诸如默认购方抬头、实付初值逻辑、付款截图金额识别，以及绑定包是否导出备注/标签，属于团队业务规则，在「设置 → 报账方案 → 管理」中维护。

## 查验单自动归档配置

Tidoc 默认常驻监测系统「下载」「桌面」与「文稿/文档」目录中新增的查验单 PDF 文件，用于[补齐材料](/guide/materials)。

- **额外归档目录**：若浏览器或打印程序默认将 PDF 保存至其他路径，点击「选择」追加监测目录；点击「清除」恢复系统默认监测范围。
- **归档后清理原 PDF**：开启后，当查验单成功捕获并复制至条目附件库后，系统原下载目录中的临时 PDF 将自动移至系统废纸篓或回收站，避免文件堆叠。

## 数据存储目录与维护

「设置 → 数据位置」清晰标识当前数据存储仓库的绝对路径，并提示属于「系统默认位置」或「自定义位置」。条目索引数据库、材料附件原始文件、导出成果快照及可选组件均集中存放于该目录中。

- **打开文件夹**：在系统文件管理器中直接打开当前数据主目录。
- **打开导出目录**：定位本地导出成果存储目录，按钮实时显示导出成果占用的存储空间。
- **清理临时文件**：安全清理拖拽解析中转文件及旧版升级安装包，释放本地磁盘空间。
- **清理旧备份**：每次核心版本升级前系统均会自动生成当前数据仓库的完整快照副本。当历史副本超过 2 份时将展现此按钮，点击可抹除较早的陈旧副本，保留最近 2 份快照。

展开「高级数据维护」支持无损迁移存储路径：

- **迁移到新位置…**：选取一个空文件夹，系统将完整迁移数据库与全量附件至新目录。迁移执行期间请勿强制退出应用。
- **恢复默认位置**：当前处于自定义目录时可用，将全量数据回迁至系统默认 Application Support / AppData 目录。

数据重构与迁移务必使用内置迁移功能，以确保数据库与附件索引的物理一致性。

## 备份与恢复

数据文件夹里的条目数据、附件、导出文件和组件需要作为一个整体进行备份和恢复。

**备份：**

1. 退出 Tidoc。
2. 在「设置 → 数据位置」确认当前数据文件夹路径（退出前也可以点击「打开文件夹」）。
3. 把整个数据文件夹复制到备份位置。

**恢复：**

1. 退出 Tidoc。
2. 把当前的数据文件夹移到别处备用。
3. 把完整的备份复制到原数据文件夹的路径。
4. 启动 Tidoc，检查报账人、条目和附件。

::: tip 提示
只想在不同电脑间带走一部分条目时，可以导出 `.tidoc` 绑定包进行交接，详见[导出、打印与交接](/guide/export)。
:::


## 本地数据隐私与联网边界说明

Tidoc 的发票条目、材料附件与偏好配置均保存在本地存储目录中，日常报账与解析完全离线运行。删除条目时，其挂载的关联附件文件将同步物理清理。

应用仅在以下明确触发的场景下产生网络访问：

- 打开国家税务总局全国增值税发票查验平台（人工查验发票真实性）。
- 主动点击批量工具条「云识别」（调用阿里云 OCR 发票识别服务）。
- 点击访问外部官方站点、GitHub 源码仓库或说明视频链接。
- 启动后或手动检测、下载、加载软件与扩展组件版本更新（详见[软件和组件更新](/update/)）。

团队方案配置文件完全由本地文件离线载入，系统绝不在后台从外部网络拉取未经授权的未知规则。

阿里云 AccessKey 仅以单机形式加密保存在当前设备，导出的 `.tidoc` 绑定包绝不夹带密钥；导入绑定包后，使用接收方本地配置的 OCR 环境。建议为 Tidoc 创建专用的最小权限 RAM 用户与 AccessKey；若更换设备或不再使用，可在阿里云控制台及时吊销旧密钥，详见[阿里云 OCR](/guide/aliyun-ocr)。
