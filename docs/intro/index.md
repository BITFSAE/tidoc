# Tidoc 简介

Tidoc 是整理报账发票和相关材料的桌面软件，支持 Windows 和 macOS。它以一张发票为一个条目，把发票、付款截图、实物图和查验单放在一起，核对后按批次导出或打印。

发票的识别在本机完成，数据和附件保存在本机，发票不会上传。

![Tidoc 主界面](/images/main-overview.png)

## 解决什么问题

报账用到的材料通常分散在聊天记录、下载文件夹和相册里。发票信息靠手工抄写，缺什么材料要到提交时才发现，多人报账时文件还要来回转发。

Tidoc 把这些事放进同一个界面：

- **整理**：一张发票对应一个条目，付款截图、实物图、查验单和备注都挂在这个条目上。
- **核对**：集中查看缺少的材料、需要核对的识别结果和实付金额差异。
- **协作**：把选中的条目连同附件导出为 `.tidoc` 绑定包，交给别人继续整理。
- **输出**：生成总览 Excel、附件整理包、材料 PDF，以及报账方案规定的 Word 文档。

个人、团队和社团都可以使用。一台电脑也可以替多位报账人整理材料。

## 发票是怎么识别的

识别是 Tidoc 的核心功能。导入发票后，软件会自动读出发票号码、开票日期、销售方、购买方、价税合计和物资明细，再检查读出的结果是否自洽。整个过程在本机完成，不需要联网。

### 1. 有 XML 就直接读取

电子发票的 XML 文件由开票平台生成，字段已经分好。Tidoc 直接按字段读取，再配上 PDF 作为票面。能拿到 XML 时优先提供 XML。

### 2. 没有 XML 就读取 PDF 里的文字

数电发票的 PDF 带有可以复制的文字。Tidoc 读取的是这些已有的文字，不需要把页面当成图片再去认字，所以速度快，也不依赖网络。

文字读出来是一长串，需要判断哪一段属于哪个字段。Tidoc 按发票票面固定的标签和格式来定位：

| 字段 | 定位方式 |
| --- | --- |
| 发票号码 | 「发票号码」后面的 20 位数字 |
| 开票日期 | 「年」「月」「日」格式的日期 |
| 购买方、销售方 | 各自的「名称」后面跟着的抬头，以及统一社会信用代码或纳税人识别号 |
| 价税合计 | 票面金额里最大的一个 |
| 物资明细 | 以 `*分类*名称` 开头的行，一直读到「合计」行为止 |

不同开票平台的版式不一样，同一张发票的文字顺序也可能错位。软件针对常见情况做了整理：购买方和销售方左右分栏、名称折成多行、同一商品后面跟着折扣行、数量单价金额粘在一起等。同一份 PDF 会按两种顺序各读一遍，第二种保留文字在页面上的位置，只有按它读出的明细合计与价税合计一致时才采用。

### 3. 用金额核对结果

读完之后做两项核对：

- 明细金额相加，应该等于价税合计。
- 购买方抬头应在已设置的抬头范围内，购买方税号应与抬头对应。

核对不通过时，条目会出现「识别提醒」，写明原因，例如「明细识别合计与发票总额相差 12.00」。提醒不会阻止你继续整理，也不会被悄悄忽略。你可以在详情里修改字段，或者用「重新识别」再读一次。

### 4. 读不出来怎么办

扫描件和手机拍的发票照片没有文字，本地识别读不到字段。可以在详情里手动填写，也可以用[阿里云 OCR](/guide/aliyun-ocr) 补齐。详细的核对步骤见[核对识别结果](/guide/check)。

## 特点

- **本地**：识别、数据和附件都在本机。只有在线查验发票、检查和下载更新、使用阿里云 OCR、打开外部链接这几类操作会联网。
- **快速**：导入后立即在本机读取，不用等网络返回。文件夹里的多张发票可以一次导入。
- **轻量**：核心程序不含打印和 OCR 的组件，需要时在软件里按需安装。
- **可核对**：每张发票都做金额核对，不自洽的地方会给出提醒，由你确认。软件已用两百余张真实发票做回归测试，遇到新的版式会继续补充样本。
- **与云识别的关系**：维护者用同一批发票对比过本地识别和阿里云 OCR。在报账使用层面，本地识别可以替代阿里云 OCR，部分发票上结果更好。因此阿里云 OCR 默认不需要安装，保留为可选的补充，用来补齐明细或提供第二份核对结果。
- **多平台**：Windows 和 macOS 都有安装包。
- **便于管理**：状态视图、标签、批次、筛选和批量操作，让多张发票可以按进度分批处理。
- **便于协作**：绑定包可以把条目和附件完整交给别人；一台电脑也可以替多人整理。

## 目前的限制

- 主要面向数电发票。其他版式可能读不全，需要手动补充，系统会用识别提醒告诉你。
- 付款截图的金额识别是实验性功能，默认关闭。它使用 Windows 或 macOS 自带的文字识别，效果有限，结果只供参考。看一眼截图确认金额并不费事，所以它的优先级不高。
- 打印和 Word 输出需要先安装「打印导出组件」，阿里云 OCR 需要先安装「OCR 识别组件」。两者都在「设置 → 组件与更新」里安装。
