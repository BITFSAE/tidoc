# 快捷操作

熟练运用键盘快捷键与鼠标交互能够显著提升[条目](/guide/concepts)归整与批处理效率。本页按业务场景归类常用快捷操作（macOS 对应 `Cmd`，Windows 对应 `Ctrl`）。

::: tip 提示
全局单键快捷键（`/`、`N`、`T`、`Cmd/Ctrl + A` 等）在主工作台卡片列表处于焦点时生效。当光标位于文本输入框内或当前存在激活的弹窗时，按键响应遵循原生输入行为，不触发列表快捷动作。
:::

## 列表选择与键盘漫游

| 快捷操作 | 功能说明 |
| --- | --- |
| 点击卡片 | 切换选中状态。选中状态下卡片呈现高亮且左边缘显示标识竖线 |
| `Shift` + 点击 | 从上次选中的卡片连续扩选至当前卡片 |
| 方向键 `↑` / `↓` / `←` / `→` | 在条目卡片之间移动焦点 |
| `Shift` + 方向键 | 沿焦点移动方向连续多选卡片 |
| `Home` / `End` | 焦点快速定位至列表首个 / 末尾条目 |
| `PageUp` / `PageDown` | 列表向上 / 向下翻动 5 张卡片 |
| 空格键 | 切换当前焦点卡片的选中/取消状态（支持 `Shift + 空格` 连续选择） |
| `Cmd/Ctrl + A` | 全选当前视图展示的全部条目 |
| `Esc` | 若当前打开了弹窗则关闭弹窗；若焦点在输入框则退出输入；否则清空当前条目选区 |

## 检索、编辑与上下文菜单

| 快捷操作 | 功能说明 |
| --- | --- |
| `Enter` | 打开当前焦点卡片的条目详情 |
| `/` | 聚焦至搜索栏，支持检索发票号、销售方、金额、备注及物资名称 |
| `N` | 唤起「新建报账条目」弹窗 |
| 右键点击卡片 | 弹出条目上下文操作菜单 |
| 菜单键或 `Shift + F10` | 在键盘焦点所在的卡片上呼出条目上下文菜单 |

条目上下文菜单包含：「打开详情」「填写实付金额」「添加付款截图」「在线查验」「上传已有查验单」「添加发票 PDF」「编辑条目备注」「打标签」「批次」与「删除条目」。安装 OCR 识别组件后追加「阿里云识别」；在特定批次视图下，「批次」自适应为「移出当前批次」，并追加「批次催办备注」。

## 标签与批量操作

| 快捷操作 | 功能说明 |
| --- | --- |
| `T` | 唤起标签管理窗口，批量为已选条目添加或移除标签（需先选中条目） |
| 右键点击批量栏「标签」 | 批量录入方案定制的报账要素字段（例如 BITFSAE 方案的采购用途、存放地点） |

勾选条目后，批量操作工具条中的「批次」「标签」「报账人」「重新识别」「云识别」（需组件）「汇总」「导出」「打印」「删除」均统一对当前已选集合生效。

## 附件拖拽与快捷文件交互

| 快捷操作 | 功能说明 |
| --- | --- |
| 拖动文件至单张卡片 | 将支撑材料直接追加至该条目，悬停时目标卡片单独高亮响应 |
| 拖动文件至主界面空白区 | 载入发票 PDF/XML 或 `.tidoc` 绑定包，其他支撑文件尝试按规则自动匹配已有条目 |
| `Cmd/Ctrl + V` 粘贴剪贴板文件 | 在条目详情中粘贴直接归入当前条目；在主界面粘贴则按拖拽至空白区域的逻辑执行 |
| 左键点击卡片「发票/付款/查验/实物」 | 为该条目追加录入对应材料文件 |
| 右键点击卡片「发票/付款/查验/实物」 | 调用系统默认关联程序直接打开已挂载的文件 |
| 在打印导出弹窗中按 `Enter` | 依据当前勾选项立即执行预检并生成交付物 |
