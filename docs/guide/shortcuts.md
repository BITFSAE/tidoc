# 省时间的操作

整理报账材料时，花时间最多的是找文件、传文件和一张张点开。下面的操作按节省时间的多少排列，前面的先用上。键盘快捷键见[键盘快捷键](/guide/keyboard)。

## 拖放和粘贴文件

把文件拖进窗口，或者先在访达、文件资源管理器里复制，再回到 Tidoc 按 `Cmd/Ctrl + V`。落点不同，文件的用途不同：

| 操作 | 效果 |
| --- | --- |
| 把文件拖到主界面空白处 | 导入发票 PDF、XML 或 `.tidoc` 绑定包，其他材料会尝试匹配现有条目 |
| 把文件拖到某张卡片上 | 添加到该条目的材料，拖动时只有这张卡片高亮 |
| 在主界面粘贴 | 与拖到空白处相同 |
| 在条目详情里粘贴 | 材料直接归入这个条目 |
| 把商家给的取票二维码图片拖进窗口，或截图后粘贴 | 联网取回发票的 PDF 和 XML，见[导入发票](/guide/import#用取票二维码导入) |

一次可以拖入或粘贴多张发票、付款截图和查验单，Tidoc 先识别文件类型再分别处理。各种落点的细节和无法匹配时的处理见[导入发票](/guide/import)。

## 右键菜单

右键点击卡片，打开条目菜单。菜单包含「打开详情」「填写实付金额」「添加付款截图」「在线查验」「上传已有查验单」「添加发票 PDF」「编辑条目备注」「打标签」「批次」和「删除条目」。安装 OCR 识别组件后多出「阿里云识别」；在某个批次里查看时，「批次」换成「移出当前批次」，并多出「批次催办备注」。

卡片上的「发票」「付款」「查验」「实物」也可以右键：直接打开该条目已有的对应文件。点击这些按钮，则继续添加对应材料。

## 批量处理

先选中多张卡片：点击卡片，`Shift` + 点击连续选择，或者用 `Cmd/Ctrl + A` 全选当前列表。选中后，批量工具条里的「批次」「标签」「报账人」「重新识别」「云识别」（安装 OCR 识别组件后显示）「汇总」「导出」「打印」「删除」作用于所有已选条目。

批量工具条里的「标签」还能为已选条目批量填写方案要求的报账信息，例如 BITFSAE 方案的采购用途、存放地点。

## 手机上的文件传到电脑

付款截图和实物照片多数在手机里。先传到电脑，再拖进 Tidoc，比在微信里逐张另存快。

[微信输入法](https://z.weixin.qq.com/)有在手机和电脑之间互传文件的功能。在手机和电脑上都安装微信输入法，并在输入法的跨设备功能里关联两台设备后，就可以把手机相册里的图片和文件传到电脑。文件到电脑后，按输入法的提示找到它们，再拖进 Tidoc。具体入口和按钮名称随输入法版本变化，以输入法里的说明为准。

::: tip 提示
直接从微信聊天窗口拖文件可能提示「无法读取」，原因见[导入发票](/guide/import#从微信拖入时提示「无法读取」怎么办)。
:::

## Windows 上看图

核对付款截图和实物照片时，要把图片一张张点开看。Windows 用户可以用[果核看图](https://pic.ghxi.com/zh/)作为看图软件。官网介绍它支持 JPG、PNG、HEIC、WebP 等常见格式，要求 Windows 10 及以上的 64 位系统，目前只有 Windows 版。

## 关于这些工具

微信输入法和果核看图是第三方软件，与 Tidoc 没有从属关系，Tidoc 的功能也不依赖它们。下载、安装和使用方式以对方官网为准。
