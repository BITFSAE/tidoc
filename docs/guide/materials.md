# 补齐材料

导入发票后，给每个[条目](/guide/concepts)补上付款截图、实物图和查验单，并确认实付金额。本页从卡片上的按钮讲到材料要求的设置。

## 在卡片上补材料

卡片右侧的按钮用于快速操作：

- 「发票」：补充发票 PDF，例如先导入了 XML 的条目。
- 「实付」：填写或修改实付金额。
- 「付款」：添加付款截图，可一次选多张。已有多张时按钮上显示张数。
- 「查验」：进入在线查验，步骤见下文。
- 「实物」：添加一张或多张实物图。实物图默认是可选材料，方案要求实物图或条目已有实物图时，才显示这个按钮。
- 「详情」：打开条目详情。没有「实物」按钮时显示为「打开详情」。
- 方案里的其他材料，例如合同、审批单：方案把它们设为卡片快捷按钮时，卡片上会多出对应名称的按钮，用法与上面相同。

已经补上的材料，对应按钮显示为已完成状态。再次点击同一个按钮，可以继续添加同类文件。右键点击按钮，直接打开已有文件，有多份时打开最近一份（「发票」优先打开 PDF）。

![卡片上的材料按钮和状态徽标](/images/card-actions.png)

右键点击卡片，条目菜单里也有这些操作，见[省时间的操作](/guide/shortcuts#右键菜单)。把文件拖到卡片上同样可以添加材料，见[导入发票](/guide/import)。

## 在详情里集中整理

适合一次处理一个条目的全部材料。点击卡片上的「详情」，或选中卡片后按 `Enter`。

1. 在「报账材料」中找到对应分组。每个分组标明「必需」或「可选」，以及已上传的数量。
2. 点击分组右侧的「＋ 添加」添加文件。查验单分组是「＋ 上传」，旁边还有「在线查验」。
3. 在文件那一行，可以「打开」文件、用「位置」在文件夹中定位、「替换」或「删除」，也可以在「材料备注」里写说明。
4. 在「需要手动确认」里填写「实付金额」「实际物资名称」和「条目备注」。修改后自动保存。
5. 把文件拖到「报账材料」区域，或打开详情后直接粘贴，材料会加入当前条目。图片按付款截图添加，实物图用对应分组的「＋ 添加」。

「实际物资名称」用于发票品名与实际采购物资不同的情况，卡片上优先显示它。

## 付款截图与实付金额

点击「付款」选择截图文件。实付金额按以下方式处理：

- 实付金额默认等于发票金额。这由方案里的「实付初值取发票总额」控制，默认开启；发票金额读不出时，实付留空。
- 实际发生分笔付款、部分付款或金额调整时，点「实付」改成真实金额。实付与发票金额不同时，卡片上标出「差异」。手动改过的实付与发票金额、付款截图识别合计都不同时，卡片还显示「已修改」，条目进入「已修改」视图，见[状态视图](/guide/check#用状态视图分步处理)；由付款截图识别填写的实付不算手动修改。

付款截图 AI 识别是实验性功能，需要先在「设置 → 开发者选项」里填写 Key，见[设置与数据](/guide/settings#付款截图-ai-识别)。开启「添加截图时自动识别」后，添加截图时直接识别；也可以选中条目，点击「云识别」，勾选「付款截图 · AI」手动识别。

识别后按下面的规则处理实付：

- 实付还空着、识别合计又等于发票金额时，自动填入实付。
- 实付已经填写（包括按发票金额默认填好的），或识别合计与发票金额不同时，不自动改，只在识别提醒里写明「识别合计与实付不一致」。打开详情，在「付款截图识别」里核对后可以点「用识别合计作实付」，这次修改记在「修改记录」里。
- 一个条目有多张付款截图时，按金额累加后再和实付比对。
- 部分退款按原付款减去已退款计算，并提示核对净支出。仅有退款记录时不推算原付款。

以下情况会出现在[识别提醒](/guide/check#出现识别提醒时怎么办)里，卡片显示「付款截图」，详情顶部列出每一条：

- 截图不是付款凭证，例如订单详情页、报销或发票列表、收入记录，提醒里写明是哪一张截图（只有一张时写「付款截图」，多张时写「第 2 张付款截图」，顺序与详情里的「付款截图识别」表格一致）和原因。
- 金额看不清、识别失败，或需要人工确认的截图。
- 识别合计与实付不一致；实付未填时与发票金额比较。
- 开启自动识别后，还没按当前规则识别的截图。

详情里的「付款截图识别」逐张列出识别金额、状态和说明，并把识别合计、实付和发票金额放在一起比较。改了实付以后会立即重新比对。深色截图提示「建议用浅色截图，打印更省墨」，仍可使用。

识别时显示完成数、排队、失败、缓存和估算费用；点提示条上的「取消」可停止还在排队的截图，已发出的请求仍会完成并计费。识别完成后，「云识别完成」窗口逐条列出识别合计、是否已填实付和需要核对的地方，点某一行打开对应条目。

## 在线查验并归档查验单

在线查验会打开国家税务总局的发票查验平台，需要联网。

1. 点击卡片上的「查验」，打开「在线查验」窗口。
2. 核对「发票号码」「开票日期」和「价税合计」。开票日期的格式是 `YYYYMMDD`。
3. 点击「打开查验官网」，等待表单显示，Tidoc 会填入这些信息。核对官网里的号码、日期和金额；信息仍为空时，可以手动填写，或关闭查验窗口后重新打开。
4. 在官网填写验证码并点击「查验」。
5. 发票详情出现后，Tidoc 会自动保存查验单。等待窗口显示「查验单已保存」，材料就已归入当前条目，无需点击官网「打印」或选择保存位置。

Windows / macOS 自动保存都使用横向版式并适当缩小，减少备注框或开票人挤到下一页的情况；内容较长时仍会保留后续页。

已经有查验单时，可以在「在线查验」窗口点「上传已有 PDF」，或在卡片右键菜单里选「上传已有查验单」，也可以直接把 PDF 拖到卡片上。

一个条目通常只保留一份查验单。条目已有查验单时，再添加会先询问：可以替换选中的一份，也可以仍添加一份。选择「仍添加一份」后，「识别提醒」会写明当前条目有多份查验单，核对后删除不需要的材料即可。在线查验时，这个询问出现在 tidoc 主窗口，软件会自动把主窗口切到前面。

自动保存失败或未能确认发票号码时，按窗口提示点击官网「打印」，在系统窗口横向另存为 PDF，或点击「上传已有 PDF」。保存到「下载」「桌面」「文档」或设置里的额外归档目录后，等待约 1～2 秒，Tidoc 会核对号码并归入当前条目。常用保存位置在其他文件夹时，在「设置 → 查验单」添加一个额外归档目录，见[设置与数据](/guide/settings#查验单)。

### 查看查验次数

Tidoc 在本机读取查验单正文里的查验次数和时间。最新可读取的查验结果为第 2 次或以后时，「识别提醒」显示次数和查验时间；第 1 次不提醒。

查验单写明「当日第 N 次」时，次数只表示查验当天的次数。次日重新查验并保存新的第 1 次查验单后，旧的次数提醒会移除。

保留多份查验单时，以正文里查验时间最晚的一份为准，缺少时间时按材料添加时间排序。这条提醒不影响材料齐备，也不调用云识别。

查验单正文里的发票号码与条目不同时，这份查验单不参与次数判断，「识别提醒」会写出两个号码，提示核对是否放错了材料。

## 设置哪些材料计入齐备

[材料齐备](/guide/concepts)取决于方案的「材料要求」。「材料要求」里只列出当前方案用到的项目：方案没有的材料、设为隐藏的材料都不会出现。可以调整付款截图、实物图、查验单和实付金额是否必需：

1. 点击右上角的「设置」，展开「开发者选项」，在「报账方案」一行点「管理」。
2. 在「材料要求」里，把列出的项目分别设为「必需」或「可选」。发票始终必需，PDF 或 XML 均可。
3. 点击「保存更改」。

方案自带的其他材料，例如合同或审批单，在「材料要求」里只读列出，名称、格式和份数要求在详情的材料分组和缺项提示里显示。方案把某类材料设为隐藏时，条目没有这类文件，详情里也不出现对应的空分组。

保存后，已有条目仍按创建时的规则处理。方案的其他设置和让旧条目采用新规则的方法，见[报账方案](/guide/schemes)。
