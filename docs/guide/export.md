# 导出、打印与交接

整理好的[条目](/guide/concepts)可以导出为 `.tidoc` 绑定包交给别人继续整理，导出总览 Excel 和附件整理包，或生成 Word 与材料 PDF 用于打印。本页按这三类操作说明。

三类操作都从选中条目开始：在主界面点击卡片选中条目（`Cmd/Ctrl + A` 选中当前列表全部），再使用批量工具条里的「汇总」「导出」「打印」。「汇总」会先列出条数、合计金额和抬头分布，可以用来快速核对。

## 交接给别人（`.tidoc` 绑定包）

### 导出绑定包

1. 选中需要交接的条目。
2. 点击批量工具条中的「导出」。
3. 勾选「绑定包」（默认已勾选），按需修改它下面的「文件名」。扩展名 `.tidoc` 由软件保留。
4. 点击「开始导出」。

完成后，「导出完成」窗口列出生成的文件，点「打开」查看文件，点「文件夹」打开所在位置。文件保存在导出目录，也可以在「设置 → 数据位置」点「打开导出目录」找到。

![导出窗口](/images/export-dialog.png)

绑定包包含条目、材料、报账人和完整性校验信息，以及条目的创建时间和修改记录。阿里云识别结果、「已识别 / 待确认」状态和付款截图的 AI 识别结果也会一起保存，接收方不用为同一张截图再识别一次；识别提醒按接收方电脑上的识别设置重新计算。接收方需要使用支持报账方案的较新版本 Tidoc。

条目备注、材料备注（含备注修改记录）和条目标签是否带出，在「设置 → 开发者选项 → 报账方案 → 管理」的「绑定包」一组里设置：「绑定包包含备注」「绑定包包含标签」，默认都开启。选中的条目属于不同方案时，各条按自己方案的设置处理；方案固定了这两项时不能修改。

::: warning 注意
绑定包里的发票、付款截图和个人信息可以直接读取。完整性校验能发现文件在传输中缺失或被改动，传输和保存时请使用团队认可的安全方式。
:::

### 导入绑定包

有三种方式打开导入预览：

- 点击主界面顶部的「导入包」，选择 `.tidoc` 文件。
- 把一个 `.tidoc` 文件拖入或粘贴到 Tidoc 窗口。
- 在文件管理器中双击 `.tidoc` 文件。

一次只处理一个绑定包，导入前需要已经创建报账人。软件已在运行时双击文件，文件会交给现有窗口；如果正在填写弹窗，导入预览会等弹窗关闭后再打开，不会打断输入。

预览里依次核对本机情况、勾选条目、安排报账批次，再确认导入。

![导入绑定包预览](/images/bindle-preview.png)

**核对本机情况**。预览顶部显示文件名，以及包内的条目、报账人和材料数量。列表里每个条目标出与本机的关系：

| 标记 | 含义 |
| --- | --- |
| 新增 | 本机没有这张发票，导入后新建条目。 |
| 已有·待补充 | 本机已有这张发票，包里有本机缺少的材料或信息，旁边列出将补充的内容。 |
| 已有·无变化 | 本机已有这张发票，包里的材料和信息本机都有，无需补充。 |

已有条目旁的「查看」打开本机的这个条目，关闭后回到预览。

**勾选条目**。默认勾选包内全部条目。点列表上方的「新增」「已有·待补充」「已有·无变化」只看这一类，搜索框可以查发票号、销售方、报账人或原批次。筛选只改变显示，不改变勾选；「已选」旁会注明筛选外还选中多少条。

- 「全选当前结果」：勾选或取消当前看到的条目，其他条目不变。
- 「仅选当前结果」：只保留当前看到的条目，其他全部取消。
- 「清空选择」：取消全部勾选。

要按人挑选，展开「报账人」，取消不需要的人。这里只列出包里有条目的报账人。

**安排报账批次**。「报账批次」决定新增条目进哪个批次：「不加入」「已有批次」或「新建批次」。选「已有批次」后在右侧下拉框选择，已归档的批次也在其中，名称旁注明「已归档」，用于把补交的材料放回已结束的批次；选「新建批次」后在右侧填写名称。有在办批次时默认选已有批次，没有时默认新建，并用绑定包文件名预填名称。

已有条目默认留在原来的批次，原来没进批次的也不动。这样补交材料时，已经整理好的条目不会被挪走。需要把它们集中到目标批次时，勾选「已有条目也移入此批次」，本次勾选的已有条目（包括「已有·无变化」的）都会移过去。每次打开预览，这一项都默认不勾选。

个别条目要例外处理时，点该行的「设置」，选择「保留原批次」、某个已有批次、「新建批次…」或「不加入批次」。单条设置优先于上方的统一设置，点「恢复统一设置」取消。每行都写明批次去向，例如「导入到 · 9 月第一批」「保留 · 9 月第一批」；已有条目要移动时显示「原批次 → 目标批次」。

**其他设置**，按需调整：

- 「报账人」：可以修改新增条目的报账人和审核人姓名，已有条目保持本机的报账人。包内姓名对应本机多位同名报账人时，需要选择对应哪一位。
- 「统一标签」：给所选条目追加一个标签，可以留空。
- 「报账方案」：本机安装了多个方案时出现，决定新增条目使用的方案；已有条目沿用本机方案。
- 「材料角色对应」：包内有合同、审批单等自定义材料时，出现在对应条目下。展开后选择本机方案里的类别；不确定用途时保留为外部材料，之后在详情里整理。

**确认导入**。导入设置作用于所有勾选的条目，导入后只能逐条改回，所以分两步确认。点「导入 N 条」后还不会写入，预览回到顶部并框出报账人和批次等设置，「导入前请核对」列出新增、已有待补充、已有无变化的条数，以及保留原批次和进入各批次的条数。有条目会进入或留在已归档批次时也会提示，导入后到「已归档」查看。设置改动后核对内容同步更新，确认无误再点「确认导入 N 条」。

补充已有条目时，Tidoc 保留本机已填写的信息，追加缺少的材料，合并备注和普通标签，并补齐本机为空的基础信息、明细和云识别记录。「已报销 / 未报销」和「已支付 / 未支付」标签按包内状态替换相反的标签，避免状态互相矛盾。

作为新条目导入时，条目保留原来的创建时间和修改记录（包括修改时间和修改人）。补充到已有条目时，保留本机条目的创建时间，包里多出来的修改记录追加进去，已有的不重复。

导入后，发票、付款截图、实物图、查验单和其他材料按原类别归入对应分组，并计入材料齐备检查。新增条目使用导入时选择的方案；补充已有条目时，沿用该条目的方案。方案没有对应类别、文件格式不符或份数超限时，文件保留在「已有材料／外部材料」中。

已有截图出现在「已有材料／外部材料」时，打开条目详情并展开该分组，在截图那一行的「调整材料角色」下拉框中选择「付款截图」。文件会移入付款截图分组，无需删除后重新上传。

整次导入作为一个整体完成，失败时不会留下导入一半的结果。

::: tip 提示
预览顶部出现「完整性校验未通过」，说明文件在传输中可能缺失或被改动。确认来源可靠后，勾选「我确认继续，导入后标记为严重问题」才能继续，导入的条目会显示为严重问题。
:::

## 导出 Excel 与附件包

「导出」窗口除了绑定包，还可以勾选：

- 「总览 Excel」：汇总条目、金额、材料状态和备注，方便负责人核对。
- 「规范命名附件包」（即附件整理包）：按抬头和每个条目分文件夹整理所选条目的原文件并压缩，条目文件夹名带序号、发票号、销售方和金额。

可以同时勾选多项，每项下面都有「文件名」输入框，可分别修改。扩展名由软件保留，不用填写。所选条目都在同一批次时，默认用批次名称命名；其余情况用导出时间命名。导出目录已有同名文件时，会提示换一个名称。这两项不需要安装打印导出组件。

## 打印与 Word

方案定义的 Word 文档、材料 PDF 等打印件由「打印」窗口生成。Word 使用各自条目的[报账方案](/guide/schemes)模板；材料 PDF 可以按方案范围拼接，也可以选择全部材料或单独一种材料。

### 安装打印导出组件

方案有 Word 文档或材料 PDF 输出时，它们由打印导出组件生成，需要先安装。组件未安装时，「打印」窗口里对应的输出显示「需要安装或更新打印导出组件」，不能勾选。

1. 打开「设置 → 组件与更新 → 软件与组件 → 管理」。
2. 在「打印导出组件」一行点击「安装组件」。
3. 安装完成后状态立即刷新，回到「打印」窗口即可勾选。

更多说明见[软件和组件更新](/update/)。

### 生成打印件

1. 选中需要打印的条目，点击批量工具条中的「打印」。
2. 在「生成内容」里勾选需要的输出。同类的方案输出和通用输出合并在同一行，内容相同的总览表直接保留一项。含收款信息的输出旁标有「含收款信息」。需要按材料单独生成时，展开「按材料分别拼接」，里面只列出所选条目已有且格式可拼接的材料，可以同时勾选多种。没有某类材料时，对应选项不出现；所选条目没有任何可单独拼接的材料时，这一段不显示。
3. 按需填写：「文档日期」「收款对象」只在所选输出用得到时出现；「补充信息」里是方案要求在导出时填写的内容，以及未进批次的条目所需的批次信息（只用于本次导出）。
4. 需要改动时展开「扩展选项」：可切换已勾选输出的材料范围、附件整理方式或表格内容，也可以调整金额口径、条目排序、材料编号、图片布局和材料排序。包含查验单的 PDF 默认勾选「剔除查验单空白尾页」（见下文）。这些改动只影响这一次，长期默认值在「设置 → 开发者选项 → 报账方案 → 管理」的「打印与导出」里设置。方案固定的项不会出现。
5. 文件名显示在勾选的输出名称右侧，需要时直接修改，扩展名保持不变。一个输出按抬头或收款对象分成几份时，文件名展开在该项下方，每份各有一行，左侧标出抬头或收款对象。窗口较窄时，文件名也会换到下方。
6. 点击「生成」。

![打印导出窗口](/images/print-dialog.png)

「剔除查验单空白尾页」在「扩展选项」的对应 PDF 分组里，组件支持时默认开启，每项 PDF 分别选择，只影响本次生成的文件。软件从每份查验单末尾检查，剔除空白页、仅剩重复页眉页脚和页码的页，以及备注栏拆到下一页后只剩空表格边框和「备」「注」标签的页，再按保留的页数编号。

![打印导出扩展选项](/images/print-options.png)

每份查验单至少保留第一页。含正文、金额、图片、印章或其他表格内容的页面，以及无法确认内容的页面都会保留，页面字少不作为剔除依据。原始材料、附件整理包和绑定包保留全部页面。打印前请打开生成的 PDF 核对；需要全部页面时，取消勾选后重新生成。选项提示需要更新组件时，先更新打印导出组件。

材料没有收齐也可以导出。缺付款截图、审核人、收款信息或方案要求的其他内容时，窗口会提醒你核对，点击「仍然生成」即可继续。金额缺失时留空，不按零计算。打印导出组件版本较旧时，缺少收款信息的文档不能生成，先更新组件。

PDF 只拼接已有且能打开的材料。缺少的材料直接跳过，不补空白页；某类材料全部缺失时，跳过这份 PDF，其余勾选的输出照常生成。损坏、加密和不能转换的文件也会提示并跳过，可以用附件整理包保留已有原件。所选输出都没有可生成内容时，窗口会提示你添加材料或选择其他输出。

「生成」会先自动检查：

- 没有问题时，直接开始生成。
- 文件名无效、模板损坏或组件不可用等问题会在窗口底部列出原因。处理后再点「生成」。
- 只有提醒时，按钮变为「仍然生成」，看过提醒后点击继续。
- 同一问题只显示一次。涉及多个条目时显示「涉及 N 个条目」，有条目发票号时，鼠标移上去可以看到。

修改输出勾选、日期、字段或文件名后，之前的检查结果失效，再点「生成」会重新检查。文件名为空、包含路径或有重名时，会提示修改；已填的名称保留，方便继续编辑。至少勾选一项输出才能生成。

每次打开窗口，方案输出的默认勾选采用方案当前设置，旧条目也一样；通用方式和按材料分别拼接沿用上次的勾选。在方案里保存了「全不选」时，方案输出保持空选择。

只有 XML、没有发票 PDF 的条目，会提示并跳过票面，已有付款截图和其他选中的材料仍可拼接。XML 不能充当票面，可以用附件整理包保留原件。

生成期间，窗口显示当前阶段，只写本次实际生成的内容，例如「正在生成总览表」「正在生成材料 PDF」；同时生成两类文件时合并说明。可计数的步骤同时显示完成数。需要中止时点击「取消生成」，当前步骤结束后显示取消结果，不会保存半套文件。取消或失败后，查看原因、调整资料，再点「生成」。

生成完成后，窗口关闭并打开「导出记录」，可以直接打开新生成的文件。

### 填写收款对象

「报账说明」等含收款信息的文档，可以先填写并选定收款对象；暂时没有填写时，会提醒你核对，仍可生成，缺项留空。方案里没有需要收款的输出时（例如通用方案），收款信息的入口不会出现。

1. 在「打印」窗口点击「管理收款信息」，也可以在「设置」的「个人收款信息」点「填写」。
2. 点击「新建收款对象」，填写收款人姓名、人员编号（BITFSAE 显示为学号，填写时保留前导零）、联系方式、账户类型、开户行和账号。收款信息只保存在本机，不会写入绑定包。
3. 回到「打印」窗口，在「收款对象」里选择本次使用的对象。留空时沿用批次或方案的默认选择。

收款方式由方案设置决定，打印窗口里不能临时修改：

- 统一收款：所有报账人使用同一个收款对象。
- 分别收款：在「设置 → 开发者选项 → 报账方案 → 管理 → 打印与导出」把「收款方式」设为「分别收款」后，要在「个人收款信息」里给每位报账人指定对象，不会回退到默认对象。此时「收款对象」一行显示「按报账人分别收款」。

检查结果会显示收款对象的名称和账号尾号。缺少内容时会列出收款人姓名、开户行或账号等缺项，Tidoc 不会自动猜测收款人。

### 查看导出记录

每次生成都会留下一条记录，保留生成时的数据。生成完成后会自动打开，之后可以在「设置」的「导出记录」点「查看」。

- 点「打开」查看单个文件，点「打开文件夹」打开所在位置。
- 点「按原数据重新生成」，使用当时的数据和空白尾页选项重新生成，不受之后修改条目的影响。原材料已删除或内容变化时会提示。
- 生成时的提醒保留在文件列表下方，可以通过发票号核对涉及的条目。
- 取消或失败的任务不会留下半套文件。

如果提示导出记录保存失败，先检查数据文件夹所在磁盘的剩余空间和写入权限。
